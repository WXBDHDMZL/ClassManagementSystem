# 班级管理系统 V2.5.0 更新摘要（考勤并入统计 + 最小窗口 + 关联补全）

- **考勤并入数据统计看板**：新增"考勤"板块——状态分布饼图 + 异常次数 Top 10 排行 + 异常人次/涉及学生数；导出的统计报表新增"考勤"工作表（状态汇总 / 按学生统计 / 逐条明细）
- **区间里只有考勤异常时也能统计与导出**（以前没有表扬/批评记录时整块统计是空的，现在会显示考勤板块并允许导出报表）
- **个人汇总单附该生的考勤异常明细**（与界面上"考勤异常 N 人次"口径一致）
- **修复窗口最小尺寸失效**：minimum 现在是 1080×680，窗口不会被拖到看不清（拖小会被立即夹回；启动恢复记忆尺寸时也会夹）。原因说明见开发交接说明
- **导出表格表头分段**：考勤表把"应到/实到"与"异常情况"分成两行，统计报表的"统计范围"与"内容"也分开，避免首行过长显示不全
- **内容包示例**：随程序附带《内容包示例/内容包_课间与自习纪律_v1.json》与使用说明，可直接在"更新与内容包"里试导入（含表扬/批评原因与考勤状态项，不含名单与时段）
- **关联补全（原有功能与新功能打通）**：学生改名后考勤不再丢失时间段与同步关联；原因改名/删除会同步更新"考勤↔批评"映射；考勤表的分类导出/导入新增"时间段"列（旧表格仍兼容）；时段/原因导出与原因管理改为跟随自定义时段；数据包额外携带自定义时段、校历、每周起始日、考勤开关与同步映射；从备份恢复后自定义时段立即生效；内容包的添加/启用/停用与运行更新包都按"更新与内容包"密码开关校验；安全页始终需要密码；当天只有考勤异常时也能导出今日记录
