# 班级管理系统 V3.2.0 更新说明

- 发布日期：2026-10-31
- 类型：删除旧密码兼容层
- 上一版：V3.1.3+132 ｜ 本版：V3.2.0+133

## 本版变更

### 1. 删除旧密码权限字段

已删除：

- `passwordForRecords` 等旧 8 个分项开关字段
- `passwordActions`
- 旧动作策略解析与回写
- `setPasswordPolicy` 旧分项参数
- 旧权限字段导出/导入处理

权限始终由“班主任管理 + 操作身份权限”固定模型决定。

### 2. 统一管理密码

已删除：

- `PasswordRelationMode`
- `headTeacherPasswordHash`
- `passwordRelationMode`
- 旧双密码模式、班主任优先/操作优先逻辑
- `AuthCredential.headTeacher`

现在只有一个管理密码字段 `passwordHash`。

### 3. 旧数据自动迁移

升级时如果旧数据只有 `headTeacherPasswordHash`：

- 自动迁移到 `passwordHash`；
- 如果旧数据同时有两套哈希，优先使用原管理入口实际验证的班主任哈希；
- 旧数据只有班主任哈希且未开启密码时，迁移后保持管理密码可用；
- 首次保存后只写入统一字段。

以下旧键会被忽略：

- `passwordForRecords` 等旧分项字段
- `passwordActions`
- `passwordRelationMode`
- `pageGates` / `reverifyMode`（此前已删除）

### 4. 清理旧测试与旧文档

- 删除旧四种密码模式测试；
- 更新恢复码、安全页、密码对话框测试；
- 更新离线恢复工具说明；
- 真机清单中的旧双密码步骤已清理。
