# 班级管理系统 V3.1.0 更新说明

- 发布日期：2026-10-31
- 类型：班主任身份权限化 + “记录身份”统一更名为“操作身份”
- 上一版：V3.0.1+128 ｜ 本版：V3.1.0+129

## 1. 班主任身份现在真正拥有管理权限

之前班主任只是记录人署名，没有特殊权限。本版改为：

```text
选择班主任身份 = 验证管理密码 + 进入班主任管理
```

具体规则：

- 在操作身份选择框点击“班主任”时，必须验证管理密码；
- 验证成功后：
  - 当前操作身份切换为班主任；
  - 同时开启班主任管理会话；
  - 拥有完整管理权限；
- 班主任管理期间可执行：
  - 修改/删除任意记录；
  - 导入记录、名单、原因、考勤、时段、校历；
  - 数据包、备份恢复、恢复出厂；
  - 更新、插件管理、安全设置；
- 退出班主任身份、超时、重启程序后，管理权限立即失效；
- 退出后自动恢复进入前的普通操作身份。

班主任管理期间由管理会话计时，不再叠加普通身份的 5 分钟闲置退出。

## 2. “记录身份”统一更名为“操作身份”

为避免把“操作身份”和“这条记录是谁登记的”混在一起，所有界面措辞统一为：

- 记录身份 → 操作身份；
- 启用记录身份 → 启用操作身份；
- 选择记录人 → 选择操作身份；
- 未选择记录人 → 未选择操作身份；
- 记录身份设置 → 操作身份设置。

记录卡片里的“记录人：××”仍然保留，因为它表示这条记录的实际记录人快照，不是权限身份。

## 3. 界面文案与历史高亮

- 操作身份选择框只保留操作指引，不写设计解释/版本变化；
- 新增 UI 文案守则：功能界面不得出现更新日志、旧版对比、迁移说明、设计理由；
- 历史记录日期多选改为有边界的选中底色，避免高亮向上溢出。
