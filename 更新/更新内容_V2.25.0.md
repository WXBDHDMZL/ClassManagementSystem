# 班级管理系统 V2.25.0 更新摘要（第二轮审查问题全部修复：数据正确性/稳定性/承诺兑现）

**数据正确性**
- 考勤同步映射值与原因文本不再允许顿号、并自动去空格（此前会让原因串无上限膨胀 2→4→6 段，统计与导出错位）
- 人工登记的考勤不再被"批评记录同步"静默改写（先登记"请假"、又录一条映射到考勤的批评，不会再无声变成"迟到"；程序会记录跳过原因）
- 启动自愈重复 ID 时，考勤上的同步关联**一并回写**（删除同步记录的撤销行为恢复可靠）
- 考勤导入覆盖状态时**显式解除**旧关联（不再出现"考勤=请假、关联批评=迟到"的自相矛盾，并留操作日志）
- 插件写入意图里的非法日期会被拒绝（不再产生脏数据键）
- 原因文本自动去空格（一个空格不再算填了原因）

**性能与批量**
- 插件批量写入与校历导入改为**一次落盘**（此前逐条写：导入一年节假日 = 上百次全库加密写盘）
- 未装任何插件时，主界面完全跳过插件快照计算

**稳定性与体验**
- 开机自启收进托盘前先确认托盘可用（托盘初始化失败时不再"后台空跑、没有任何界面"）
- 设置·插件页 4 处回调补齐 mounted 检查（消除"偶发点了没反应"）
- 考勤/名单/原因/时段/校历导入的**文件读取全部加异常兜底**（损坏文件给出中文提示而不是"点了没反应"）
- 导入判重键在时间列缺失时自动降级（同一份文件反复导入不再产生重复记录）
- 删除学生/原因失败时给出明确提示（不再毫无反馈）
- 插件参数写盘前先读回合并（同一插件挂在卡片+页面时不再互相覆盖）

**安全与导出**
- 导出文件名前缀清洗（`..\` 等路径字符不再能写到导出目录之外）

**工程**
- 删除未被引用的 admin.manifest；build.bat 补 `cd /d` 与两处错误码检查（失败不再误报"完成"）
- 新增数据正确性回归测试
