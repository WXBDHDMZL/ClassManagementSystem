# 班级管理系统 V1.5.0 更新摘要（设置与数据管理）

- **设置面板改为入口式**：点设置后是一列可点击的设置项（主题 / 窗口 / 时间段 / 名单与原因库 / 导出与导入 / 备份与恢复 / 安全 / 关于），每项带当前值摘要，点击后在同一个窗口内切换到子页面，左上角返回，不再跳整屏
- **时间段可自定义**：9 个时段的名称与时间范围都能改（如把"上课"改成"第一课堂"并调整时间），记录时的自动预选、列表显示与导出都会跟随；可一键恢复出厂时段
- **数据管理支持分类导出/导入**：记录、学生名单、原因库、时间段设置都能单独导出为表格、单独导入（名单/原因库可选合并或替换）；另有一键导出/导入完整数据包（含记录、名单、原因库、时段，不含操作密码）
- **备份与恢复（独立成页）**：备份位置可单独指定（默认文档目录下的"班级管理系统_备份"）；自动备份可选"仅手动 / 每次退出 / 每天 / 每 3 天 / 每周"；备份文件固定一份、新的覆盖旧的；恢复时直接列出备份位置里的备份供选择，也可浏览其它位置
- **启动窗口行为**：可选"记住上次的大小与位置 / 每次默认大小 / 启动即最大化"
- **更完整的操作保护**：改动记录、名单、原因库、时间段以及导入记录、从备份恢复都需要输入操作密码
- 新增"修改操作密码"：设置里输入当前密码即可改成 4-20 位的新密码；密码只在本机加密保存，忘记后无法找回
- 数据统计新增「对比与关注」：表扬批评比、与上一段等长区间（上周/上月）的环比增减、以及需关注学生名单（区间内批评 ≥ 3 次，附表扬次数）
- 统计看板支持切换图表：折线图 / 柱形图 / 饼图（选择会被记住）；导出的统计报表内含汇总、明细、每日统计、对比与关注四张表
- 修复导出报表中"汇总"工作表为空的 bug（底层改名后引用失效导致内容丢失）
- 名称不再写死范围："导出周报/月报"改为"导出报表"，导出文件名为"统计报表_起_至_止"（区间可能是任意天数）
- 原历史记录里的"导出排名"功能移到了统计看板（按当前区间导出排名表；区间内只有一种记录时只导出对应那一张表，不再出现空白工作表）
- 饼图改为"学生占比"：展示所选类型（批评 / 表扬，可切换）下各学生的记录占比
- 学生选择统一为同一种选择框（搜索 + 勾选，追加记录与统计明细共用），统计明细可直接从名单里选人并看到区间内的表扬/批评次数
- 新增可自定义项：记录对话框默认操作类型（表扬 / 批评 / 上次用过的）、是否按时刻自动预选时段、学生卡片字号缩放
- 悬浮球去掉外圈描边；小球与托盘右键菜单会即时跟随深色/浅色切换；"导出路径"统一管理所有导出（含数据备份）
