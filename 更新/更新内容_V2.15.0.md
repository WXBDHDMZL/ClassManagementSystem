# 班级管理系统 V2.15.0 更新摘要（插件能"自己排布局"了：页面 / 控件 / 图表 / 自由画布）

- **插件现在可以有自己的页面**：插件列表里会多出一个「打开插件页面」，点开就是插件自己设计的界面
- **插件能用的界面组件**：
  - 基础：文字 / 小标题 / 分隔线
  - 控件：数字输入框 / 开关 / 文本输入框 / 下拉选择 / 按钮
  - 排列：横向 / 纵向（可嵌套最多 8 层）
  - 数据：**表格**、**图表（柱状 / 折线 / 饼图）**
  - **自由画布**：插件提交绘制指令（矩形 / 圆 / 线 / 弧 / 文字），**想怎么画就怎么画**；点画布会**把坐标回传给插件**，因此能做出可交互的画面
- **交互闭环**：你改一个控件 → 程序把新参数连同数据快照再喂给插件 → 插件返回新界面 → 程序重画（插件不用、也不能直接操作界面）
- **示例插件升级**：现在带一个完整页面——数字输入 + 下拉选择 + 学生明细表 + 柱状图 + 可点击的画布；改数字或切指标，界面立刻重算。这就是"插件自己排布局"的实际样子
- **新增《插件开发规范》**（替换原《内容包制作规范》）：清单字段、七项权限、两个入口函数、输入数据结构、全部控件与绘制指令，以及必须遵守的硬性要求
