# 班级管理系统 V2.13.0 更新摘要（悬浮球：玻璃背景实时跟随 + 质感加强）

- **玻璃背景实时跟随**：以前只在球出现那一刻采集一次背景，之后画面是"冻结"的——别的窗口在球下方变了、关了、移走了，球里还是旧画面（"残留其他窗口的颜色"就是这个原因）。现在球下方的画面**每 0.15 秒跟着桌面更新一次**，窗口一动球里就跟着变
- **做到"不闪"的关键**：让球窗口对**截屏隐身**（Windows 的 `WDA_EXCLUDEFROMCAPTURE`）——这样采集背景时**不需要把球藏起来**，既不闪、也不用做拼接
  - ⚠️ **副作用**：从此**任何截屏 / 录屏都拍不到这个球**（你自己截桌面、录演示视频也一样）。要让它出现在视频里，跟我说，我加一个开关
  - 旧版 Windows 不支持该能力时会自动退回"低频刷新"，功能不受影响
- **质感加强**（把各家液态玻璃六层架构里的"滤镜"层补上）：
  - 折射强度 0.46 → **0.50**
  - 边缘模糊范围更宽（球面像差更明显，边缘"化开"的过渡更长）
  - 新增**滤镜层**：玻璃内的画面**略提饱和 + 微提亮**，透出来的内容更通透、有生气
