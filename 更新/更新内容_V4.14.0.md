# V4.14.0

本版是数据安全与发布链更新。

## 主要变化

- 数据文件升级为 LRX3，每台电脑使用随机数据密钥，并由 Windows DPAPI 保护；程序不再内置固定密钥。
- 手动备份支持独立备份口令，生成 `.enc` 与 `.pkey`，可在新电脑恢复；自动备份仍只支持同一 Windows 用户、同一台电脑恢复。
- 更新包增加 Ed25519 签名校验。缺少签名或验签失败时，更新器会拒绝安装。
- 修复更新下载域名白名单、自启动状态判断、安装器卸载残留。
- Excel 导出纳入班主任管理；导出成功提示会说明文件包含学生姓名等明文信息。
- 修复跨零点“今日”归属、覆盖导入后的考勤一致性、恢复出厂失败回滚、时段导入确认、统计导出类型开关等问题。
- 原因库替换/重置在未授权时会明确失败，不再显示成功。

## 从 V4.13.7 及更早版本升级

1. 先备份整个数据目录（默认在“文档\班级管理系统”）。
2. 安装 V4.14.0 后，从开始菜单运行一次“转换旧版加密数据”。
3. 转换完成后再启动程序。

绿色版用户请运行安装包内附带的 `migrate_lrx2.exe --data-dir "<数据目录>"`。未转换的旧版数据会被拒绝写入，程序不会覆盖原文件。

旧版日志与旧备份也需要用该工具转换后才能在新版中读取。

## 发布资产

- `ClassManagementSystem_Setup_v4.14.0.exe`
- `ClassManagementSystem_Setup_v4.14.0.exe.sha256`
- `ClassManagementSystem_Setup_v4.14.0.exe.sig`

安装包未做 Authenticode 代码签名，Windows SmartScreen 可能提示未知发布者；更新器会校验 Ed25519 签名，校验失败不会安装。
