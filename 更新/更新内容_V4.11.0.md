# 班级管理系统 V4.11.0 更新说明

- 发布日期：2026-11-21
- 类型：更新体验调整
- 上一版：V4.10.0+171 → 本版：V4.11.0+172

## 本版目的

让用户启动程序时就能看到可用的正式版本，并减少更新过程中的操作步骤；更新入口仍集中在「设置 → 关于」。

## 调整内容

### 启动更新提示

- 开启“启动时检查更新”后，程序在后台检查 GitHub 上的正式发布版本。
- 发现可用版本时，在主界面弹出紧凑的更新卡片：显示当前版本、可用版本、安装包名称与大小、版本内容。
- 卡片提供“稍后”“跳过此版本”“立即更新”三个操作。
- “跳过此版本”会记住该版本号；在该版本被更新覆盖前，启动时不再自动提示。
- 从托盘或悬浮球后台启动时不弹窗，避免提示出现在隐藏的主窗口里；可从关于页手动检查。

### 更新操作

- 点击“立即更新”后直接下载安装包，不再要求输入管理密码。
- 下载过程中显示进度；下载完成后按 GitHub 摘要或同名 `.sha256` 文件校验，校验通过才启动安装。
- 安装前程序自动退出，安装完成后重新打开。

### 关于页

- 关于页的“检查更新”与“查看”使用同一套下载与安装流程。
- 不再提供“选择本地安装包”入口。

## 兼容性说明

- 不改变主数据、加密、备份与日志文件格式；已有数据、备份、日志继续可用。
- 新增的“跳过此版本”记录保存在设置中；旧数据没有该字段时按未跳过处理。
- 升级只替换程序文件，不删除「文档\\班级管理系统」中的记录、名单、原因库、设置、日志或备份。
