# 班级管理系统 V4.0.0 更新说明

- 发布日期：2026-11-07
- 类型：功能移除版（破坏性变更）
- 上一版：V3.7.1+143 ｜ 本版：V4.0.0+144

## 本版目的

完全移除插件功能。程序不再提供插件管理、插件页面、插件角标、插件统计区块、插件附加报表和插件权限入口，也不再加载任何旧插件。

插件数据从未写入主数据，也不在自动备份范围内；移除插件不会改写记录、学生名单、原因库、设置或考勤数据。

## 移除内容

- 删除插件运行时、插件清单/UI 模型、插件注册表、插件服务、插件示例、插件角标与诊断；
- 删除插件管理界面、设置入口、主界面插件卡片、顶栏插件按钮、学生卡片角标、统计看板插件区块和报表插件附加工作表；
- 删除插件写入、安装、管理三个密码动作；
- 删除 `flutter_js` 依赖及 QuickJS 原生运行库，删除仅供插件使用的 `archive` 直接依赖；
- 删除 `插件开发规范.md`、插件专项测试和验证清单中的插件章节；
- 旧插件目录 `文档\班级管理系统\插件` 不会自动删除，目录内文件也不再被程序读取；确认不需要后可自行删除；
- 旧插件写入的历史记录仍按普通记录保留，不删除、不改写。

## 兼容性说明

- 本版不接受旧插件，导入手工保留的插件包也不会恢复插件功能；
- 插件功能移除属于破坏性变更，因此版本号升至 V4.0.0；
- 主数据格式、加密格式、备份格式和恢复流程不变；旧版数据可直接被本版读取；
- 升级安装只替换程序文件，不会删除 `文档\班级管理系统\` 下的数据。
