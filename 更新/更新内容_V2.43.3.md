# 班级管理系统 V2.43.3 更新说明

- 发布日期：2026-10-31
- 类型：身份普通模式权限细分
- 上一版：V2.43.2+125 ｜ 本版：V2.43.3+126

## 本版做了什么

给每个身份增加三项普通模式权限：

```text
允许新增记录
允许考勤登记
允许本人编辑窗口
```

规则：

- 开启：普通模式可直接执行；
- 关闭：该操作需要进入管理员模式；
- 班主任固定保留完整权限；
- 默认全部开启，升级后原有体验不变；
- 管理员模式不受这些开关限制。

### 1. 允许新增记录

关闭后：

- 该身份仍可作为记录人署名；
- 但不能在普通模式新增单条/批量/历史追加记录；
- 新增入口会提示“当前身份没有普通模式新增记录权限”；
- 进入管理员模式后可正常新增。

### 2. 允许考勤登记

关闭后：

- 普通模式不能登记/修改考勤；
- 考勤登记会提示需要管理员模式；
- 进入管理员模式后可正常登记。

### 3. 允许本人编辑窗口

保留上一版能力：

- 开启：窗口内可改删自己创建的记录；
- 关闭：只能署名，改删需要管理员模式。

## 升级与回退

- 覆盖安装或直接运行新构建即可；
- 新增权限字段对旧身份默认开启，升级后原有行为不变；
- 关闭“启用管理员模式”可回退旧身份/权限行为。
