# 班级管理系统 V2.25.1 更新摘要（错误安全网：任何错误都有提示、不崩）

- **发布模式下，某个界面出错显示友好提示页**而不是灰色/红色错误面板——提示"这一页显示出了问题，但你的数据是安全的"，错误已自动写入错误日志
- **主界面新增"数据写入失败"横幅**：写盘失败时持续提醒（此前失败标志没有任何界面呈现，用户完全不知情），详情见"关于 → 查看操作日志"
- 核查确认：全局兜底（FlutterError / 平台异常全部记入错误日志、不向外抛出）此前已有效

**已知现象（待后续原生修复）**：悬浮球模式下用桌面快捷方式打开程序，主窗口会先短暂闪现——根因是快捷方式的二次启动由**原生层直接显示主窗口**（`main.cpp` 的 `ShowWindow`），此时悬浮球尚未收起；彻底修需要把"唤起"改为消息通知、由 Flutter 侧先收球再显示主窗口。
