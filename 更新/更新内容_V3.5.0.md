# 班级管理系统 V3.5.0 更新说明

- 发布日期：2026-11-01
- 类型：统计报表结构优化
- 上一版：V3.4.2+139 ｜ 本版：V3.5.0+140

## 背景

V3.4.2 已经删除没有意义的“合计”，但表扬和批评仍挤在同一张“汇总”表里，只是按列分开。两类记录性质不同，混在一张表里查看、筛选和打印都不直观。

## 改动

### 汇总拆成两张工作表

统计报表不再生成单张“汇总”表，而是按实际数据类型生成：

- `表扬汇总`：学生姓名、表扬次数；
- `批评汇总`：学生姓名、批评次数。

规则：

- 两种记录都存在时，生成两张表；
- 只有一种记录时，只生成对应的那一张；
- 某张表只列出该类型次数大于 0 的学生，不再用 0 占行；
- 两张表都不再出现“合计”列，也不把表扬和批评相加。

### 导出选项

“设置 → 导出与导入 → 导出选项”中的“汇总（表扬/批评）”一项同时控制上述两张表；取消勾选后两张都不导出。其余“明细 / 每日统计 / 对比与关注”选项不变。

### 每日统计

每日统计仍是“日期 + 实际存在的类型列”，不改口径。
