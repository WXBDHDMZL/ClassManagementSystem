# 班级管理系统 V1.2.0 更新说明

- 发布日期：2026-09-25
- 类型：数据管理、名单/原因库维护与统计看板
- 上一版：V1.1.2 ｜ 本版：V1.2.0

## 本版改了什么

### 1. 数据备份与恢复

- 新增备份与恢复能力：可备份当前数据，也可从备份文件恢复。
- 恢复前有确认提示，避免误覆盖当前数据。
- 备份文件同样保存在本机，不上传网络。

### 2. 名单与原因库可在程序内维护

- 学生名单可在程序内增删改，不再需要改代码。
- 表扬/批评原因库可在程序内维护；原因改名会同步更新历史记录中的原因文本。
- 名单与原因库的修改均纳入操作密码保护。

### 3. 数据统计看板

- 新增统计看板：表扬/批评次数、占比、趋势与需关注学生。
- 新增个人汇总单、周报、月报等报表导出。
- 统计结果与记录数据同源，导出文件可直接用于班级总结。

### 4. 与网页版的关系

- 网页版的学生名单、原因库写在 HTML/脚本里，电脑版从 V1.2.0 起可以在程序内维护。
- 网页版的数据仍在浏览器 `localStorage`；电脑版备份/恢复只处理电脑版数据，不读取网页版存储。
- 网页版旧数据迁移仍需后续提供导出/转换工具，不能直接用电脑版备份功能恢复。

| 项 | 结果 |

| 备份/恢复 | 备份文件可生成，恢复后数据可读 |

| 原因维护 | 改名同步历史原因文本 |

## 升级与回退

- 覆盖安装即可；旧数据没有名单/原因库字段时使用内置默认值。
- 回退到 V1.1.2 前建议先备份，旧版不识别新增的统计与备份设置字段时会使用默认值。
