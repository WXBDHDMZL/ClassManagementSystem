# 班级管理系统 V2.33.0 更新说明

- 发布日期：2026-10-17
- 类型：新功能（批量记录、顶栏天气、开机启动目标）
- 上一版：V2.32.2+106 ｜ 本版：V2.33.0+107

## 本版改了什么

### 1. 主界面批量记录

- 学生名字区域第一格新增一个低对比度的“批量”按钮，和卡片背景融为一体。
- 点击后打开多选学生对话框，选中后复用现有的“批量追加”对话框：
  2 人及以上一次写盘，1 人按单人追加处理，日期为当天。
- 网格和最小窗口尺寸按“多一格”重新计算，保证学生姓名仍完整显示。

### 2. 顶栏天气

- 日期时间同一行增加天气：城市、天气图标、天气描述和温度。
- 点击天气或“设置天气地区”可以搜索并更换城市；天气数据来自 Open-Meteo，
  不需要 API Key，只发送城市名与坐标，不涉及任何学生数据。
- 天气约每 30 分钟刷新一次；断网时显示“天气暂不可用”，不影响记录等主功能。

### 3. 开机启动到托盘或悬浮球

- “随 Windows 启动”现在可以选择启动后进入 **托盘** 或 **悬浮球**（默认托盘）。
- 选择悬浮球时，开机后主窗口不弹出，直接在桌面显示悬浮球；托盘图标仍然保留，
  随时可以从托盘菜单恢复主界面。
- 启动参数分别写入 `--tray` / `--ball`；启动失败或托盘初始化失败时自动恢复主窗口，
  不会出现“后台空跑但没有任何界面”的情况。

### 4. 兼容性

- 新增的天气与启动目标字段都有默认值；旧数据缺少这些字段时按“未设置天气 /
  托盘”处理，升级不影响已有数据。
