# 班级管理系统 V2.18.0 更新摘要（插件可以往程序各界面里加内容了：挂载点）

- **新增"挂载点"机制**：插件不再只能有自己的页面，还能把内容加到**程序已有的界面上**
- 插件在清单里声明要用哪些挂载点（如 `"slots": ["main.cards"]`），程序渲染那个位置时会问插件"这里要放什么"，插件返回内容即可
- **已开放的挂载点**：

  | 挂载点 | 位置 |
  |---|---|
  | `main.cards` | 主界面右侧面板顶部（卡片） |
  | `main.headerActions` | 主界面顶栏（按钮） |
  | `statistics.sections` | 统计看板底部（区块） |
  | `settings.sections` | 设置 · 插件页（区块） |

- **程序自带界面完全不受影响**：没有插件往某个位置加内容时，那里**不会留空白**
- **数据没变就不重复调用插件**（内部带缓存）：主界面频繁重建也不会拖慢程序
- **示例插件已升级**：现在会往主界面右侧面板加一张「本周需关注 N 人」的卡片，门槛还能当场调；同一份插件同时拥有"自己的页面"和"主界面卡片"
- 《插件开发规范》新增第 11 节「挂载点」（清单写法、已开放位置、注意事项）
