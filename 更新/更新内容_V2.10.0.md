# 班级管理系统 V2.10.0 更新摘要（全面审计修复 + 统计口径可配置）

### 修复的问题

- **修复"从备份恢复"失效**：备份文件的校验只认旧格式，导致本版本导出的备份一律被判为"文件格式不正确"、无法恢复（备份形同虚设）。现已同时支持新旧格式，并保留"先校验、失败绝不改动现有数据"的保护
- **修复"关闭批评后仍生成批评记录"**：停用某个记录类型后，记录对话框会按"启用的类型"打开；编辑历史记录时会明确提示当前类型已停用
- **修复"计为未到"设置被改回**：手动把某个考勤状态改为"到校"后，再新增状态项不会再被按名称推断改回来
- **修复记录导入的 CSV 编码提示**：非 UTF-8（Excel 默认另存的 GBK/ANSI）会明确提示"另存为 CSV UTF-8 或改用 xlsx"，不再静默导入乱码
- **修复时间段"导出 → 导入"丢自定义时段**：改为按文件内容整体套用，时段的增删、顺序与名称都能还原
- **修复考勤导入的列识别**：改为按表头列名定位（在 Excel 里调换列顺序也能正确导入）；没有表头的老表格仍按旧列序兼容
- **修正导入记录的提示文案**：导入的记录标记为"导入"（原来误写成"追加"）

### 新增：统计口径可配置（设置 → 导出与导入 → 统计口径）

- **需关注学生阈值**：区间内批评达到该次数即进入"需关注"名单（1–20 次，默认 3 次）
- **排行显示条数**：表扬 / 批评 / 考勤异常三个排行共用的 Top N（3–50，默认 10），界面标题会随之显示（如"表扬 Top 5"）

### 其他改进

- 记录导出（今日 / 单日 / 合并 / 全部）统一按"日期 + 时间"升序排列，与定期自动导出同一口径
- 个人汇总单里的考勤异常同样排除校历放假日（与界面、统计口径一致）
- 数据包新增"计为未到"名单，换电脑后无需重设；考勤导入时新增的状态也会按名称推断"计为未到"
- 考勤对话框与考勤表会显示"名单外学生"的记录条数（已从名单移除但留有考勤）
- 给全班批量追加记录改为一次写盘，操作更跟手（原来每名学生都要写一次盘）
