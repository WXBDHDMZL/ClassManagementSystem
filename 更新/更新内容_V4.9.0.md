# 班级管理系统 V4.9.0 更新说明

- 发布日期：2026-11-14
- 类型：隐私清理版（非破坏性）
- 上一版：V4.8.3+161 → 本版：V4.9.0+162

## 本版目的

清理源码、Git 历史与发布产物中的个人信息，避免真实学生名单和旧作者身份随程序、仓库或安装包扩散。本版不改变数据格式和日常使用流程，现有记录、名单、原因库、设置与备份均保留。

## 调整内容

- 程序不再内置真实学生名单。首次启动、数据解析失败和恢复出厂都使用空名单；名单页提供“清空名单”，不再提供“恢复默认名单”。
- 空名单状态保留明确引导，可前往「设置 → 记录与名单 → 名单与原因库」添加或导入学生。
- 作者署名统一为 `WXBDHDMZL`，保留联系邮箱；关于页、底栏、README、用户条款、LICENSE、安装器属性和 Windows 版本信息同步更新。
- 重建 `main` 与 `glass-attempt` 的 Git 历史，移除历史中的真实名单、旧截图和旧作者信息；旧历史只保留在项目外备份中，不随仓库分发。
- 使用清理后的源码重建 Windows Release、调试符号和安装包；旧安装包与旧构建产物不再作为交付物。
- 数据加密密钥不再以含旧作者标识的明文字符串保存，改为编码常量；密钥值不变，现有 LRX2 数据仍可直接读取。
- 安装包不再包含已下线的校历导入、网页版迁移工具等旧内容。

## 兼容性说明

- 不新增、不删除持久化字段，不改变数据、加密、备份或恢复格式。
- 升级只替换程序文件，不删除「文档\班级管理系统」中的记录、名单、原因库、设置或备份。
- 已有用户数据不会被清空；空名单只影响新安装、损坏数据回退和恢复出厂。
- 从旧版本升级不需要先卸载，也不需要迁移数据；建议升级前关闭旧程序并保留现有备份。
