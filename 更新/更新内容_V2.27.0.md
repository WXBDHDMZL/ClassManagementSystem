# 班级管理系统 V2.27.0 更新摘要（全面检查发现的全部问题一次性修复）

**数据正确性**
- **统计看板缓存改用"数据指纹"**：此前用"有记录的天数"当数据版本，同一天内新增/修改/删除记录后看板会**静默显示旧数字**；现在由数据内容本身算出指纹，数据一变就重算（并附界面级回归测试）
- **统计"较上期"与导出报表口径统一**：上一区间没有记录时统一显示"暂无法对比"（此前屏幕按 0 基准显示"表扬 +7"）
- **单条写入与批量写入合并为一套实现**：此前两份实现分别造成"插件写入被标成导入""不登记考勤""空时段键不规整"三处不一致，现在共用同一构造与副作用
- **导入判重覆盖"时间列存在但整列为空"**（此前只处理"表头缺列"）；同一重复行出现两次时"重复 N 条"不再虚高
- **记录/校历解析时跳过的损坏数据写入错误日志**（此前静默丢弃，排查"数据少了"时毫无线索）

**安全与承诺**
- **插件读权限真正生效**：按清单声明的权限裁剪数据快照——没声明 `readStatistics/readRoster/readAttendance` 时，对应字段**根本不存在**（此前只声明 `log` 的插件照样能拿到全班姓名与次数，权限徽章形同虚设）；试跑、插件页、统计挂载点、导出四处统一按权限裁剪（**注：本版漏了"学生卡片角标"这第五处，已在 V2.27.1 补上**）
- 插件包新增**单文件 50MB 上限**与**文件数量 500 上限**（配合原有总量上限，防构造包）

**稳定性与体验**
- 插件数值参数被改成非数字时**退化为默认值**而不是报错打断页面
- 插件一次请求写入超过 200 条时整体拒绝并明确说明
- 历史"选中之间"多日期列表改用按需构建（跨整学期不再一次性构建上千条记录，打开更顺、内存峰值更低）
- 名单/原因库/时段导入的**解析**也纳入异常兜底（此前只兜住了文件读取）

**工程与流程**
- 备份轮换改为**按文件名排序**（不再依赖文件修改时间），消除偶发测试失败
- 统一圆角（34 处）、弱化文字色（57 处）、危险按钮样式（5 处）为同一常量/助手；Excel 建表与编码收敛为单一入口（21 处），避免依赖升级时漏改
- 所有"只打印调试信息"的错误兜底（33 处）现在**同时写入错误日志**，"点了没反应"从此可排查
- 写盘不等待改为显式声明（`unawaited`），语义不再靠约定
- 文档补齐：提交前检查清单、行为修复标准流程（写用例→改根因→**回退验证**）、依赖复核要求（升级 `flutter_js` 必须重跑网络探针）、打包前放置 `VC_redist.x64.exe` 的步骤
