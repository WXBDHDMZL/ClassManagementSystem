# 班级管理系统 V3.3.0 更新说明

- 发布日期：2026-10-31
- 类型：暂停考勤功能，保留数据
- 上一版：V3.2.1+134 ｜ 本版：V3.3.0+135

## 本版变更

### 1. 移除考勤主界面入口

已隐藏：

- 主界面「考勤」按钮；
- 设置「考勤」入口；
- 统计页考勤板块；
- 记录导出中的考勤附表；
- 设置页考勤记录/状态导入导出；
- 报表导出中的考勤工作表；
- 插件读取考勤数据的能力。

考勤功能暂停，不再作为当前主产品功能展示。

### 2. 删除现有考勤记录

已按用户要求清理当前数据文件中的全部考勤记录：

- 删除前考勤记录：5 条；
- 删除后考勤记录：0 条；
- 原表扬/批评记录：记录数已脱敏，全部保留；
- 主数据文件与 `.bak` 均已清理为 0 条考勤；
- 写入前已生成数据文件备份。

主数据清理备份位置：

```text
<数据目录>\class_management_data.enc.attendance_cleanup_backup_2026-10-31T22-05-53-437264
```

旧 `.bak` 备份：

```text
class_management_data.enc.bak.attendance_cleanup_backup_2026-10-31T22-34-43-060
```

自动备份目录中的历史备份未批量改写；如需要连历史备份也彻底清除考勤，需要单独确认后再处理。

### 3. 停止考勤自动同步

当前版本关闭：

- 表扬/批评记录 → 自动生成考勤；
- 考勤异常 → 自动生成批评记录；
- 记录编辑/删除 → 联动考勤；
- 导入记录时补登考勤。

历史考勤数据字段继续保留在数据文件和备份中，未来 DLC 可继续使用。

### 4. 保留底层数据与能力

保留：

- `AttendanceRecord`；
- `attendanceByDate`；
- 考勤状态与同步映射设置；
- 数据包/备份中的考勤字段；
- 考勤引擎与数据兼容测试。

这样后续恢复/DLC 不需要重新做数据迁移。

### 5. 功能门控

新增统一开关：

```text
AttendanceFeature.enabled
```

生产默认 `false`，所有界面、统计、导出、插件与自动同步路径统一受控。
