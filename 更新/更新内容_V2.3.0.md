# 班级管理系统 V2.3.0 更新摘要（考勤时间段 + 考勤与批评双向同步 + 校历）

- **修复考勤选学生只能单选**：登记考勤里的学生选择框漏传"可多选"，之前只能选一人（整个程序里的多选入口都已复查）
- **顺带修掉同类误导**：单选场景（如统计选学生）此前也用复选框显示，看起来像能多选，现在改为单选按钮，行为与外观一致
- **考勤登记改为与"记录"一致的三步**：选学生（可多选）→ 选时间段（新增"全天"）→ 选考勤状态；同一学生同一天的不同时间段可各记一条（如早读迟到、上课请假）
- **考勤与批评记录双向同步（映射可配置）**：登记"迟到 / 早退 / 缺勤"会自动在批评里生成对应原因（迟到 / 早退 / 旷课）的记录；反过来在记录里选这些原因也会自动登记考勤；撤销考勤、清空时段或删除记录时另一边同步删除。映射可在"设置 → 考勤"里逐项修改（⇄ 按钮），留空表示不生成批评记录（如"请假"）
- **考勤文案统一为时间段口径**：异常记录按时间段分组展示、按钮改名"清空全部时段"、导出考勤表新增时间段列
- **新增"校历"设置页**：每周起始日可选周一 / 周日 / 周六（周日就要返校时选周日，统计的"本周"与环比随之调整）；可把法定假日标为"放假"、把调休后的周末标为"调休上学"，统计的"记录天数"不计放假日期，考勤在放假/调休日会给出提示
- **安全页密码开关增至 8 项**（新增"校历"）
- **记录对话框提示**：选中会同步考勤的批评原因时，直接提示"保存后会同步登记考勤"
- **安装包许可协议同步**：LICENSE.txt 与应用内《用户使用条款》内容一致（并标注版本）
- 导出今日记录/单日记录时附当天考勤异常（按时间段）
