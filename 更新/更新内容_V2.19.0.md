# 班级管理系统 V2.19.0 更新摘要（插件能力全开：六个挂载点 + 更多数据 + 参数保存 + 日志通知）

- **挂载点全部接通**，插件现在可以往这六个位置加内容：
  - 主界面右侧面板顶部（卡片）
  - 主界面顶栏（按钮）
  - 统计看板底部（区块）
  - 设置 · 插件页（区块）
  - **学生卡片角标**（批量：一次返回全班，如"批 3"）
  - **导出报表时追加自定义工作表**
- **数据 API 扩充**：今天的记录、考勤统计（按状态 / 按人）、历史趋势（最近 8 周 + 最近 6 个月）、原因使用次数与原因库、每个学生最近 5 条记录；新增 `readAttendance` 权限
- **插件设置会自动保存**：页面或卡片上带 `key` 的控件，用户改过的值会存下来（`plugin_data\<插件id>.json`），重启后还在
- **插件能写日志与弹提示**：返回值里带 `logs`（需 log 权限）会写进操作日志；带 `notify` 会以浮动提示显示——顶栏按钮最常用这一招
- **示例插件全面升级**：一个插件同时演示六个挂载点 + 自己的页面 + 试跑 + 日志 + 通知
- 《插件开发规范》同步补齐：新权限、全部数据字段、六个挂载点的两种契约、参数保存、日志与通知
