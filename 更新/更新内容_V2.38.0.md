# 班级管理系统 V2.38.0 更新说明

- 发布日期：2026-10-24
- 类型：本地文件全量加密
- 上一版：V2.37.0+114 ｜ 本版：V2.38.0+115

## 本版改了什么

### 1. 日志、锁定状态与插件状态改为加密存储

- 操作日志、错误日志、密码失败锁定状态、插件启用状态、插件参数，全部改用与主数据同级的 LRX2 加密格式保存。
- 日志导出前会解密为明文；日志文件扩展名仍是 `.txt`，但内容已是密文。
- 主数据与备份的原有 `.enc` 格式保持不变，已有数据不需要重新导入。

### 2. 旧明文文件自动迁移

- 启动时会把历史操作日志、错误日志、插件启用状态与插件参数迁移为加密格式；之后写入时也会自动迁移。
- 迁移只影响本机存储格式，不改变日志内容、插件启用结果或参数值。
- 旧明文文件在成功迁移前仍可读取，迁移失败不会阻断程序启动。

### 3. 明确保持明文的内容

以下内容仍保持可读，便于用户使用或插件作者编辑：

- 用户主动导出的 Excel、设置方案、数据包、插件包；
- 插件代码 `plugin.json` / `main.js`；
- 更新包与诊断报告。

### 4. 安全边界说明

- 密钥内置在程序中，安全级别与主数据 `.enc` 相同，属于“防误看、防损坏”，不等同于操作系统账户隔离或企业级密钥保护。
- 插件代码与用户主动导出的文件不加密。

## 升级与回退

- 覆盖安装即可；首次启动会自动迁移旧明文日志与插件状态，建议升级前先备份整个数据目录。
- 回退到 V2.37.0：旧版不识别新的加密日志/插件状态文件，日志可能显示为空、插件状态可能需重新设置；主数据、备份、名单、记录与考勤不受影响。回退前请保留完整备份。
