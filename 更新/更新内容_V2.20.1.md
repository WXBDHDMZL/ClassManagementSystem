# 班级管理系统 V2.20.1 更新摘要（重要修复：插件在真程序里根本跑不起来）

- **修复：所有插件都显示"渲染超时"**（同一份插件在 Node 里跑却完全正常）。两个原因叠加：
  1. 插件脚本原本放在**后台线程**执行，而 JS 运行时**无法在后台线程初始化**（它依赖 Flutter 绑定，会直接崩溃，表现为"超时"）→ 改为在**主线程**执行
  2. 一处字符串转义写错，导致脚本收到的是字面量 `$entryPoint` 而不是真正的函数名 → 插件一调用就抛错
- **修复：出错不再"静默超时"** —— 现在会报出真实原因（例如"ReferenceError: xxx is not defined"），排查插件问题容易得多
- **顺带扫出并修掉同类转义错误共 6 处**：其中两处在"导出插件包"上（文件名和提示文字此前会显示成 `${manifest.id}.zip` 这样）
- **如实更新说明**：由于运行时的限制，**插件脚本无法被强制中断**（原先承诺的"超时强杀"做不到）。因此规范把"**必须快速返回、不要写死循环**"列为硬性要求；程序会统计耗时并在过慢时提示
- **验证方式升级**：新增"启动时真跑一次插件并把结果写成文件"的诊断手段，今后凡是改动插件执行链路都能自证（这次就是靠它定位到根因的）
