## 一、本版变化

### 1. 家长会模式 + 个人汇总单（统计看板新入口）

- 统计看板标题栏新增**家长会模式**按钮：按学生逐个查看——
  该生在所选区间内的表扬/批评/记录天数/考勤记录、全部记录明细，
  "上一位/下一位"快速翻人；
- **导出个人汇总单（Excel）**：概要 + 记录明细 + 考勤明细一次成表，
  家长会/个别谈话随用随导。

### 2. 随机点名（今日记录面板新按钮)

- 从当前名单随机抽一位学生，大字展示；
- 支持"排除已被点过的"——一轮点完自动重新开始，轮流提问不重复。

### 3. 学生卡片今日角标

- 卡片**左上角绿色** = 今日表扬次数，**右上角红色** = 今日批评次数，
  像手机 App 的角标；角标悬浮在卡片角上，**不改变名字框的大小**；
- 无记录时不显示，界面依旧干净。

### 4. 小组与小组统计

- 名单管理新增**小组管理**：新建小组、勾选成员（分组跟人走——
  学生改名自动迁移、移除自动清除、替换名单自动清理失效分组）；
- 统计看板新增**小组筛选**：选定小组后，全部统计只算该组成员；
- 小组与班级事件随**数据包**一起导出导入（换电脑不丢）。

### 5. 班级事件（与校历并行）

- 日历设置新增**班级事件管理**：班会、考试、收作业提醒等自定义日程；
- 当天有事件时，主页"今日记录"面板顶部自动提示"今日事件：……"。

### 6. 导出/导入补缺

| 新增 | 说明 |
| --- | --- |
| 校历标记导出/导入 | "日期 / 类型"两列表格，与原有批量导入合并使用 |
| 操作日志导出 | 数据页一键另存全量操作日志 |
| 错误日志导出 | 数据页一键另存错误日志（便于发给别人排查） |
| 设置方案导出/导入 | 主题、字号、时段、校历、导出选项等全部个性化设置一键迁移；**密码与本机门禁开关不随方案迁移** |
| 数据包增强 | 小组归属与班级事件并入数据包 |

### 7. 名单/原因批量导入的位置说明（本来就有）

名单与原因库的批量导入/导出**一直都有**：设置 → 数据 → 分类导出与导入
（名单支持"合并补充"与"整体替换"两种模式，原因库按三列表格往返）。

## 四、升级与回退

- **升级**：退出程序 → 运行新安装包覆盖安装 → 数据与插件自动保留，无需任何设置。
- **回退**：如遇问题，用备份文件替换 `class_management_data.enc` 即可回到升级前状态
  （程序每次启动前会自动备份一份，位于同目录的 `班级管理系统_备份\`）。
- **建议**：升级前先自行复制一份数据文件留存，最为稳妥。
