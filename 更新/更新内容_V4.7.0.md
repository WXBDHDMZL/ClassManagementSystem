# 班级管理系统 V4.7.0 更新说明

- 发布日期：2026-11-07
- 类型：交互调整版（非破坏性）
- 上一版：V4.6.3+155 → 本版：V4.7.0+156

## 本版目的

调整悬浮球右键菜单的“快速记录”：去掉“追加记录”，让“表扬”和“批评”都支持一次选择多名学生并批量录入。本版不改变主数据、加密格式、备份格式与记录字段。

## 功能调整

- **去掉“追加记录”**：悬浮球右键菜单 → 快速记录中只保留“表扬…”和“批评…”，不再提供“追加记录…”。历史记录页的事后追加入口保持不变。
- **表扬/批评支持多选**：点击“表扬…”或“批评…”后，学生选择框改为多选，可一次勾选多名学生。
- **批量模式**：选择 2 名及以上学生时，按批量新增的记录门禁处理，并打开批量记录对话框；只选 1 人时仍按单条新增处理。
- **预选类型**：从“表扬…”进入时记录对话框预选表扬，从“批评…”进入时预选批评；批量对话框同样预选对应类型。

## 交互说明

- 学生选择框支持搜索、全选、清除，并显示“已选 N 人”。
- 批量记录仍沿用现有的密码/班主任管理门禁；取消密码或取消选择不会写入任何记录。
- 批量保存成功后，顶部提示仍支持一次撤销整批新增。

## 兼容性说明

- 主数据、加密、备份、恢复流程不变，V4.6.3 数据可直接升级；
- 不新增或删除持久化字段；
- 不删除 `文档\班级管理系统\` 下的数据，升级安装只替换程序文件。
