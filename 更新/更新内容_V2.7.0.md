# 班级管理系统 V2.7.0 更新摘要（日志不限量 + 删除确认 + 节假日批量导入）

- **操作日志不再限量**：去掉 512KB 上限与"最多显示 400 条"，日志全量保留、界面展示全部记录
- **删除记录加确认**：点记录上的删除图标后，先弹确认框（显示学生、表扬/批评、原因、时间段、时间，并提示"删除后无法撤销；若是考勤同步生成的记录，对应考勤也会撤销"），确认后才按密码策略验密删除——避免误删
- **节假日安排批量导入**：设置 → 校历 → "批量导入节假日安排"：把国务院通知里的日期直接粘贴进来即可（一行一条，支持 `2026-10-01 至 2026-10-07 放假`、`2026/10/01`、`2026.10.01` 等写法，"放假/休假/休息"记为放假、"上班/调休/补班/上学"记为调休上学），也可选择"日期 / 类型"两列的表格文件导入；一次导入即完成当年校历
- **随程序附带 2026 年安排**：`校历导入/2026年节假日安排.csv`（放假 33 天 + 调休上班 6 天，据国务院办公厅通知整理），可直接在"校历 → 批量导入 → 从表格文件导入"里选它；同目录《使用说明.md》里有可直接粘贴的文本版
