# 班级管理系统 V4.7.1 更新说明

- 发布日期：2026-11-07
- 类型：缺陷修复版（非破坏性）
- 上一版：V4.7.0+156 → 本版：V4.7.1+157

## 本版目的

修复 V4.0.0～V4.7.0 审计中确认的问题，重点处理快速记录的类型一致性、悬浮球今日计数、学生搜索关闭后的窗口尺寸和撤销快照时序。本版不改变主数据、加密格式、备份格式与记录字段。

## 修复内容

- **快速记录不再静默换类型**：在设置 → 记录中停用“表扬”或“批评”后，悬浮球右键菜单中的对应项会灰化；即使通过旧菜单或异常入口触发，程序也会明确提示该类型已停用，不再自动切换成另一种类型写入记录。
- **今日计数跨零点刷新**：程序跨零点持续运行时，悬浮球右键“今日：表扬 X · 批评 Y”会立即按新的一天刷新，不再停留在前一天的计数。
- **关闭学生搜索后释放窗口空间**：关闭“主页学生搜索”后，最小窗口尺寸不再继续预留搜索框高度，学生网格可以获得更多空间。
- **撤销快照时序修正**：修改记录时先准备好撤销快照，再通知界面；监听者在通知中立即撤销时，不会误用上一条操作的快照删除原记录。
- **收起到托盘失败时保持状态一致**：如果原生隐藏悬浮球失败，程序不再误认为球已收起；托盘菜单仍显示“退出悬浮球”，可以重试或正常退出。

## 交互说明

- 停用记录类型后，悬浮球菜单对应项呈灰色；点击无效。
- 其他快速记录、批量记录、撤销和悬浮球菜单行为保持不变。
- 取消操作、取消密码或取消选择仍不会写入任何记录。

## 兼容性说明

- 主数据、加密、备份、恢复流程不变，V4.7.0 数据可直接升级；
- 不新增或删除持久化字段；
- 不删除 `文档\班级管理系统\` 下的数据，升级安装只替换程序文件。
