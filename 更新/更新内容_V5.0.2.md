# V5.0.2

本版是一次全量代码审查后的集中修复：修掉了 7 个可能导致数据丢失或误判的严重问题，以及 20 余项中等风险与体验问题。数据格式未变化。

## 主要变化

- **数据更安全**：主数据文件损坏且备份也读不出时，程序会停止写入并提示，不再用空库覆盖原文件。
- **改名不再串组**：修改某个时段的原因名称，只影响该时段的历史记录，不会改到其他时段。
- **时段快照保留**：删除自定义时段后，旧记录仍显示当时的时段名，不会变成空白或“未知时段”。
- **「全天」可反查**：导入与手填的“全天”记录能正确归入全天时段，不再被判为未知。
- **恢复失败不回滚**：备份已经写盘但读取校验失败时，暂停写入并提示重启，不会把旧内存数据写回去覆盖刚恢复的文件。
- **CSV 解析更严格**：按 RFC 4180 处理引号，字段中间的裸引号不再吞掉后面的行；引号未闭合会明确报错。
- **名单导入更省事**：复制粘贴带标题行（如“七年级一班名单”）的名单时，标题不会被当成学生姓名。
- **密钥指纹缺失可自愈**：`.keyid` 缺失或与密钥不匹配时，先用 `.bak` + 当前密钥尝试恢复并记日志；仍解不开时区分“密钥不可用”与“内容损坏”，前者暂停写入、绝不重建密钥覆盖旧数据。
- **导出选项不再静默回退**：取消全部导出列会明确拒绝并提示，不会偷偷恢复默认列。
- 另外修复了导入合并、统计口径、日志归档、更新下载（重定向/取消/长度校验）、悬浮球 DPI 与关机落盘等 20 余项问题。

## 升级说明

从 V5.0.1 可直接覆盖安装，数据格式与目录布局未变化；升级后首启动会照常读取现有数据文件。

**本版更换了更新签名密钥**：V5.0.0 / V5.0.1 的旧密钥对已不可用，那两个版本无法自动更新到本版（会在验签阶段停止并提示签名校验失败），请手动下载安装包覆盖安装一次；装上本版后，后续版本恢复自动更新。
