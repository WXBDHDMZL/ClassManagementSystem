# 班级管理系统 V3.3.1 更新说明

- 发布日期：2026-10-31
- 类型：考勤隐藏收尾
- 上一版：V3.3.0+135 ｜ 本版：V3.3.1+136

## 本版变更

### 1. 维护页不再显示考勤数量

- 数据文件说明不再显示“另有 N 条考勤异常记录”；
- 记录总数与覆盖天数保持不变。

### 2. 数据页说明同步

- 考勤隐藏时，数据包说明不再主动展示考勤功能；
- 数据包和备份中的考勤字段仍保留，供未来 DLC 或维护导出使用。

### 3. 补充隐藏后的回归测试

新增验证：

- 考勤关闭时，考勤登记不会反向生成批评记录；
- 考勤关闭时，导入记录不会补登考勤；
- 数据包导出/解析仍保留考勤字段；
- 本地加密数据仍能读回考勤字段；
- 记录面板不显示考勤入口。

### 4. 历史考勤维护导出工具

新增本机维护工具：

```text
tools/attendance_maintenance/
```

用途：

- 不进入安装包；
- 不在程序界面显示；
- 从加密主数据或旧备份导出历史考勤 Excel；
- 只读输入文件，不修改原数据。
