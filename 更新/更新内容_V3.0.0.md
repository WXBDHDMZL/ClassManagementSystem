# 班级管理系统 V3.0.0 更新说明

- 发布日期：2026-10-31
- 类型：权限体系正式替换（破坏性行为变更）
- 上一版：V2.43.3+126 ｜ 本版：V3.0.0+127

## 核心变化

新权限模型不再作为“可选模式”，而是唯一运行逻辑。
旧版逐动作密码、页面验证、30 分钟会话不再参与运行。

```text
普通模式：查看/导出 + 按身份权限新增记录、登记考勤、本人窗口
管理员模式：其余敏感操作统一验证一次
```

## 已移除

- “启用管理员模式”开关；
- 旧「操作权限」页面（动作开关、预设、页面进入验证、重复验证策略）；
- 旧逐动作密码验证分支；
- 旧 30 分钟会话授权；
- “选择班主任记录人需要密码”的旧逻辑；
- 旧区域门禁字段参与运行判断的代码。

## 现在的固定规则

### 普通模式

- 查看记录/历史/统计；
- 普通 Excel 导出；
- 新增记录（按身份“允许新增记录”）；
- 考勤登记（按身份“允许考勤登记”）；
- 本人窗口内改删自己创建的记录（按身份“允许本人编辑窗口”）。

### 管理员模式

以下操作统一需要管理员模式：

- 修改/删除他人记录；
- 超出本人窗口的记录；
- 导入记录/名单/原因/考勤/时段/校历；
- 数据包、备份恢复、恢复出厂；
- 修改时段、名单、原因、校历；
- 程序更新、插件管理；
- 修改身份/权限/安全设置。

管理员模式：

- 输入一次班主任密码；
- 按活动闲置超时退出；
- 手动退出、重启立即失效；
- 一次进入可完成一批操作，不再逐动作弹密码。

## 每个身份的权限

身份只保留三项普通模式权限：

```text
允许新增记录
允许考勤登记
允许本人编辑窗口
```

默认全部开启；关闭后对应操作需要管理员模式。

## 数据兼容

- 旧数据文件、旧备份、旧数据包仍可读取；
- 旧动作权限字段、旧页面验证字段、旧管理员模式字段仅做解析兼容，不再决定运行行为；
- 旧记录没有创建者 ID → 只能管理员模式改删；
- 旧密码、恢复码、密码模式保持不变；
- 旧身份默认获得三项普通权限，升级后体验尽量平滑。

## 回退说明

- 本版不再提供“切回旧权限模式”的开关；
- 需要旧行为时只能回退旧版本程序；
- 新数据字段对旧版本是可忽略的，但旧版本不会使用新的本人窗口/管理员模式规则；
- 升级前仍建议手动备份数据。
