# 班级管理系统 V2.11.0 更新摘要（统计看板：全部记录、分档阈值、饼图改进）

- **新增"全部记录"区间**：统计看板的时间区间除了本周 / 本月 / 近 7 天 / 近 30 天 / 本学期，现在多了一个**"全部记录"**——从最早一条记录那天一直算到今天，用来总览这个班从接手到现在的整体情况
- **"需关注学生"改成按区间长度分三档**（三档都在 **设置 → 导出与导入 → 统计口径** 里可调）：
  - 一周（本周 / 近 7 天）：批评 **≥ 3 次**
  - 一个月（本月 / 近 30 天）：批评 **≥ 8 次**
  - 一学期及以上（本学期 / 全部记录）：批评 **≥ 20 次**
  - 自定义区间按天数自动落到对应档位；看板标题会显示当前这一档用的是多少次
- **饼图两处改进**：
  - **颜色改成绕色轮取色**（相邻扇区色相相差 26°），不再出现"同一个颜色深浅不一、分不清哪块是哪块"
  - **占比不足 5% 的扇区不再标注百分比**（以前小扇区的文字会互相压在一起），具体数值仍能在图例里看到
  - 新增 **"显示全部项目"** 开关：默认只显示前 8 项、其余合并为"其他"，打开后显示全部项目
