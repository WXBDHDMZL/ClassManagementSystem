# 班级管理系统 V2.17.0 更新摘要（插件发布模式：导出插件包，可加密源码）

- 插件列表里新增「**导出插件包**」：把插件打包成一个 `.zip`，别人导入即可安装
- 导出时可以勾选「**加密入口脚本**」：
  - 包里只有 `main.js.enc`（**密文**）和清单，**用记事本打开看不到源码**
  - 对方导入后**功能完全正常**（程序在内存里解密后交给沙箱执行）
  - 每次加密都带随机数，同一条源码两次加密结果不同
- **自用插件不用加密**（保持明文最好改）
- **诚实说明**：加密只能挡住"把文件拷走直接读"，挡不住刻意逆向——所有跑在别人电脑上的代码都是这个性质（Minecraft 的付费 mod 也一样）。要更强得绑定机器 / 联网授权，那是另一套东西
- 《插件开发规范》新增第 11 节「发布模式」
