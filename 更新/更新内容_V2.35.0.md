# 班级管理系统 V2.35.0 更新说明

- 发布日期：2026-10-24
- 类型：数据正确性、统计口径与日常显示修复
- 上一版：V2.34.2+111 ｜ 本版：V2.35.0+112

## 本版改了什么

### 1. 考勤同步不再删改老师手动填写的原因

- 一条批评记录同时对应多个原因时（例如「迟到 + 早退」），考勤侧同步不再把原因删成只剩一条。
- 只有备注为「考勤同步」的自动生成记录会按考勤状态重写；老师手动录入或修改过的记录保留原原因。
- 修复后，记录内容、操作日志和统计结果保持一致。

### 2. 主文件损坏时先隔离，不用空库覆盖

- 启动读取主数据失败时，先把损坏文件原子改名为 `.corrupt_时间戳`，保留可抢救副本。
- 在用户确认前不再自动用空库覆盖主文件；隔离失败时保存会被拒绝，并提示路径。
- 适用于主文件损坏、硬盘瞬时读取失败等场景，避免不可逆数据丢失。

### 3. 放假日期的统计口径统一

- 放假日期的表扬/批评记录，现在统一计入表扬总数、批评总数、记录天数、趋势和每日统计。
- 考勤统计的“放假排除”规则保持不变，仍按考勤自己的口径。
- 修复此前“总数包含、趋势却不包含”的同一份报表数字自相矛盾问题。

### 4. 跨天自动刷新今日数据

- 程序常驻到第二天时，自然日 0 点和窗口重新恢复时会自动刷新今日记录、日期与角标。
- 已经打开的对话框不会被强制刷新，避免打断正在进行的登记或编辑。
- 仍以系统时钟为准；系统时间被手动大幅修改时，刷新时点会随系统时钟变化。

### 5. 批量记录标识与考勤导出调整

- 通过主界面「批量」入口新增的记录会标记为「批量」，今日记录与历史记录不再显示「追加」。
- 历史数据里没有批量标记的旧记录仍按原样显示为「追加」，不影响内容。
- 考勤表只展开异常名单，其余正常出勤合并为“其余正常出勤 N 人”，表格更短。
- 记录导出只在考勤功能开启时附带考勤异常；关闭考勤后不再出现空考勤列。

- 覆盖安装即可，旧数据自动兼容；批量标记为新增字段，旧版会忽略。
