# 班级管理系统 V3.1.1 更新说明

- 发布日期：2026-10-31
- 类型：权限模型第一批审计问题修复
- 上一版：V3.1.0+129 ｜ 本版：V3.1.1+130

## 本版修复

### 1. 主动退出操作身份会结束班主任管理

- 在操作身份选择框点“退出当前身份”时：
  - 清空管理会话授权；
  - 取消管理计时器；
  - 清除待恢复的旧身份；
- 不会再出现“退出身份后，管理计时器到点又把旧身份恢复回来”。

### 2. 恢复出厂 / 整包还原 / 从备份恢复会清理管理会话

- 数据整体替换后：
  - 结束当前班主任管理；
  - 清空活动身份；
  - 清空待恢复身份；
  - 重新同步身份状态；
- 避免旧管理授权跨数据继续生效。

### 3. 考勤同步更新记录时保留创建者

- 考勤同步修改已有记录的同步原因时，保留：
  - `createdByIdentityId`
  - `createdAtIso`
- 新生成的考勤派生记录也写入当前创建者；
- 普通身份不会因为一次考勤同步就失去本人窗口。

### 4. 班主任管理期间不再启动普通身份闲置计时

- 班主任管理只由管理会话计时；
- 修改设置、导入设置方案等操作不会重新创建 5 分钟身份闲置计时；
- 不会再出现“管理会话被身份闲置提前结束”。

### 5. 旧独立密码数据的安全页修复

- 安全页修改管理密码时，按管理入口实际使用的 credential 验证；
- 修改成功后，把新哈希同步到旧操作密码/班主任密码字段，并统一为合并模式；
- 旧独立模式数据也能正常设置/修改管理密码。

### 6. 移除失效的“班主任也随闲置退出”设置

- 该开关在 V3 班主任管理制度下已无实际作用；
- 已从操作身份设置页移除；
- 普通操作身份仍按闲置时长自动退出；
- 班主任管理时长继续由管理会话设置控制。
