## 汇总范围

自重新接手起，先后完成三块工作；全部修复均带回归测试，关键修复做了"撤修复 → 回归失败 → 恢复 → 全绿"的回退验证：

1. **全项目审计 86 项**（高 3 / 中 24 / 低 58）：分四批修复，覆盖数据层、界面、桌面与原生层。
2. **外部代码审查报告 36 项**（高 9 / 中 13 / 低 14）：快修批、性能批、收尾批三批落地；其余经确认属"明确不建议 / 误报 / 已拍板保持现状"的项按要求未动（见文末）。
3. **期间衍生修复**：性能批引入的"跨线程丢自定义时段"由复查自查发现并修复（P0）；一处全量测试偶发（固定等待）改为条件等待。

功能范围与界面操作保持一致（用户可感知的变化见文末一节）。

## 一、数据安全与正确性

### 三个 P0（审计发现）

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 撤销考勤 / 改状态 / 清空时段会连带删除老师手录的批评记录 | 误删真实数据 | 只清理带"考勤同步"标记的自动记录，手录的一律保留；删除记录同理只撤派生考勤 |
| 定期自动导出缺"备注"列、不遵循导出列设置、非原子写 | 备注丢失；导出文件再导入时全部判不重、整批重复入库 | 补"备注"列、按导出选项的列设置导出、改原子写 |
| 导入设置方案会覆盖本机导出 / 备份 / 自动导出路径与跨零点迁移标记 | 路径被改、凌晨记录日期被前移 | 导入时剥离本机路径与迁移标记，不再写回 |

### 跨线程时段丢失（性能批衍生，自查修复）

- Excel 导入 / 导出移入后台线程后，自定义时段在后台拿不到 → 导入的"时间段"变空、导出显示裸 key（`custom_xxx`）；修复为"主线程取时段快照、随任务传入后台"，并新增判别式测试（撤掉快照即精确失败，恢复后全绿）。

### 导入 / 导出 / 判重

- 判重口径统一（日期 + 姓名 + 类型 + 时间 + 原因 + 时间段 + 备注）；"文件内重复"与"与现有记录重复"分开计数与提示
- 日期必须真实存在（`2026-13-45` 之类拒绝入库）；文本型 ISO 日期（`2026-10-01T08:30:00Z`）可导入；时间越界不再被静默改写为边界值
- 非 UTF-8 的 CSV / 数据包明确报错，并给出"另存为 CSV UTF-8"的指引（不再静默导入乱码）
- 旧数据包缺"每周起始日 / 考勤开关 / 校历"等字段时保持本机现值；显式空值才是清空
- 整包还原与补充导入分离；导入考勤清空外部记录链接（防本机删记录时误删导入考勤）
- 原因库导入按列数判定布局；记录表头重名列 first-wins；Excel 时间型单元格保留时分秒
- 排行榜并列名次统一；操作日志查看器跨月拼接完整

### 备份与写盘

- 备份 `.bak` 改原子复制（中途掉电不再留下截断备份）；导出目录先建、文件名统一消毒
- 从备份恢复前先等排队写盘结束（防旧内存回写覆盖）；恢复 / 整包还原后派生缓存立即失效，并补跑两个幂等迁移

## 二、性能与流畅度

- **Excel 解析与导出全部移出界面线程**（导入预览；统计报表 / 考勤 / 全部记录 / 名单 / 原因库 / 时间段 / 校历导出），数千行的大表不再卡死界面
- **密码校验与改密移出界面线程**（PBKDF2 两万轮约数百毫秒，输密码 / 改密码不再冻结）
- 订阅粒度收窄：主题骨架（MaterialApp）与设置面板不再因"改一条记录"整块重建
- 数据指纹缓存修正（去掉按时间过期重算）；历史 / 明细 / 选择列表与学生网格补稳定 key；统计图表独立重绘
- 趋势与每日统计的"逐日补齐"加 2 年上限（超长区间不再渲染上千个点、工作表行数不再爆炸）

## 三、界面与交互

- 破坏性操作确认统一为红色确认按钮（删除 / 清空 / 撤销 / 关闭密码 / 恢复出厂两步确认 / 整包还原）
- 学生选择器新增"已选计数 / 全选 / 清除"；考勤登记默认不预选状态
- 历史记录空态提示；插件角标移至右下，不再与"今日批评"角标重叠
- 记录对话框缓存原因使用次数（大原因库不再每次重建全库扫描）
- 窗口与桌面：记忆位置支持左侧副屏负坐标并夹回可见区；开机自启动随程序移动自动校正；双击启动等待窗口出现再唤醒（消除"双击没反应"）；悬浮球启动即下发外观；退出流程兜底加固
- 多处提示对齐实际行为：导入跳过行数如实提示、非 UTF-8 专用引导、数据包导出的明文提示等

## 四、工程与质量（用户不可见）

- 依赖方向治理：models→services 与 services→providers 的反向依赖消除（接口化，编译期护栏）
- 共享助手与文件按职责归位 / 正名；日期与时间工具归一（原先 6 种实现）
- lint 增强 4 条（`avoid_print` / `prefer_single_quotes` / `prefer_const_constructors` / `avoid_relative_lib_imports`）并清零违规
- 服务层补齐测试：写入中断故障注入（rename 失败时原文件不被截断、临时文件被清理）、错误日志落盘 / 降级 / 限流与保序
- 测试规模 518 → 614 项（新增 96 项）；消除一处全量测试偶发（固定等待改条件等待）

## 用户能感知到的变化

- 日常功能与操作路径不变；主要感受是**更流畅**（大表导入导出不卡、输密码不冻结）与**更不容易误删 / 误改**（撤销考勤、删除记录都只动派生数据，手录数据一律保留）
- 可见的小改动：破坏性确认按钮统一红色；学生选择器多了"全选 / 清除"；考勤登记不再预选状态；插件角标位置调整；双击启动响应更快

## 按决定保留现状（非缺陷）
