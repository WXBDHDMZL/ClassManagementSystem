# 班级管理系统 V2.42.0 更新说明

- 发布日期：2026-10-24
- 类型：统一通知体系（顶部最上层长胶囊）
- 上一版：V2.41.1+119 ｜ 本版：V2.42.0+120

## 本版改了什么

### 1. 所有操作提示统一到顶部最上层长胶囊

- 原来有两套提示：顶部悬浮提示（2 秒）和底部 SnackBar（4 秒，身份/插件使用）。
- 现在统一为窗口顶部居中的长胶囊，位于顶栏下方、所有设置页和对话框之上。
- 提示最多宽 720px，圆角 28，带状态图标；普通提示为浅蓝/深蓝，错误提示为浅红/深红。
- 普通提示约 2.5 秒自动消失，长文案最多显示两行，避免遮挡；不再有底部条。

### 2. 通知层不拦截操作

- 通知层本身不接收鼠标/触摸，胶囊出现期间背后的按钮、输入框仍可正常操作。
- 这解决了“提示挡住下一次点击”的隐患。

### 3. 队列与去重

- 同一时刻只显示一条瞬时提示，其余按顺序排队，不再叠成多层。
- 相同文案、相同类型在排队期间去重，避免连续点击产生重复提示。
- 通知结束后自动切下一条。

### 4. 数据保存失败改为常驻胶囊

- 数据写入失败时，顶部显示深红色常驻胶囊，持续提醒“最近的改动可能未保存”。
- 保存恢复后自动消失，不需要手动关闭。
- 不再使用原来的顶栏下方整条红色横幅。

### 5. 身份与插件提示迁移

- 未选择记录身份的提示从底部 SnackBar 迁到顶部胶囊，随后仍正常打开身份选择框。
- 插件 `notify` 提示、插件参数保存失败提示、插件设置页的轻提示，全部统一到顶部胶囊。

### 6. 模态弹窗没有改成胶囊

- 删除确认、恢复出厂、密码输入、恢复码、身份选择、关闭窗口、更新确认等仍保留居中模态框。
- 原因：这些操作需要阻塞、输入或明确确认，变成非模态胶囊会削弱数据安全。
- Windows 更新失败提示仍由系统 MessageBox 显示（程序退出后无法使用 Flutter 通知层）。
