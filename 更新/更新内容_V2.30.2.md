## 一、安全加固（最重要）

### 1. 插件运行环境现在有硬性保护

- 插件（扩展程序）**写死循环或狂吃内存**时：程序会在 **5 秒 / 64MB** 处由运行时
  中断并报错，**程序本身不会崩、数据不会丢**（此前没有任何上限，一个坏插件
  就能把程序撑爆）；
- 插件 id 增加**保留名黑名单**：此前一个恶意插件包取名 `plugin_data` 或
  `plugins_state.json`，导入后即可**清空所有插件的设置 / 让全部插件显示为停用**；
- 插件包解压改为**边解压边计数**：此前的三道大小检查读的是压缩包自己声明的
  尺寸（可伪造），"解压炸弹"能绕过 → 现在按真实解压量中止；
- 插件源码加密增加**防篡改校验**：被改过任何一位的加密插件会拒绝加载
  （此前可被静默篡改后照常执行）；旧的加密插件包仍然兼容。

### 2. 操作密码更抗破解

- 新设置的密码改为**随机盐 + 多轮派生**（PBKDF2-HMAC-SHA256，2 万次迭代），
  不再是"无盐单轮 SHA-256"（4 位密码此前可被秒级穷举）；
- **原有密码照常可用**（升级不会把既有密码锁死），改密码时自动升级为新格式。

### 3. 插件数据权限补漏

- 只申请"统计"权限的插件**不再能读到每人的考勤明细**（此前藏在学生数据的
  嵌套字段里绕过权限）；
- 权限裁剪改为**默认拒绝**：今后程序新增的数据字段，在显式登记权限前
  不会下发给任何插件。

## 二、数据完整性修复（防静默出错）

| 修复 | 使用者能感知的表现 |
| --- | --- |
| 统计摘要指纹补上"日期" | 极少数情况下"记录天数"显示不刷新（改了记录日期后看板不变）的问题 |
| 撤销考勤不再残留空日期 | 此前批量撤销后会多出**空的考勤日期入口**，点进去什么都没有 |
| 导入/整包还原校验日期 | 表格里格式错乱的日期不再被当成合法数据吞掉（跳过并写日志），导入提示的条数也与实际一致 |
| 表格导入兼容"带时间"的日期格 | 日期列在 Excel 里显示成 `yyyy-mm-dd hh:mm` 时，此前**整表导入失败**（用户只看到"跳过 N 行"），现已正确识别 |
| 记录列表接口返回只读副本 | 消除"调用方误改导致数据被静默清空、不落盘"的隐患（内部加固） |
| 重复导入不再多写一条 | 文件内自重复的行不再被"覆盖重复"逻辑误写进库 |
| 覆盖重复保留原记录时间 | 表格没有时间列时，覆盖不再把原本的时间改成 00:00:00 |
| 校历导入逐格识别类型 | 一行里同时写"10-01 放假、10-05 调休上学"时，10-05 不再被错标成放假 |
| 校历日期范围不再截断 | 导入"整学期/整年放假"区间时，此前只标前 60 天（**静默丢弃**），现在完整导入 |
| 原因库两列表格可导入 | 按"类型 / 原因"两列整理的原因库，此前**一条也导不进来且无提示** |
| 设置方案不再带走本机路径 | 换电脑导入设置方案后，不会在对方电脑上凭空创建 `D:\班级备份` 并往里写数据 |
| 整包还原不再共享可变引用 | 内部加固：避免还原后修改包对象连带改动程序状态 |
| 日期工具口径统一 | `2026-02-31`、`2026-13-45`、`+1` 这类畸形日期不再被滚动/放行 |
| 跨时区/夏令时修正 | 日期序列与天数计算不再出现"重复某天""少算一天"（中国无夏令时，属前瞻性修正） |

## 三、稳定性与体验

- **插件相关**：
  - 插件页面遇到脚本读不出来时给出可读错误并可重试（此前**永远转圈**）；
  - 导入损坏/乱码的插件包不再让插件页**按钮全部永久失效**（此前需重启程序）；
  - 停用某个插件后，剩下插件的界面与设置不会再**串到别的插件**上；
  - 插件的数值控件遇到异常值（Infinity、上下限颠倒）不再让页面崩溃；
  - 表格控件行列不齐时不再崩溃/错位；
  - 插件"试跑 / 插件页"现在能收到界面控件的值（此前官方演示插件的开关
    **全都无效**）；
  - 写入确认框显示**来源插件名**，写入条数以实际写入为准（此前可能报"已写入 3 条"而实际 0 条）。
- **其他**：
  - 密码输入框新增**显示/隐藏**切换（教室一体机触控屏盲打易错）；密码错误后
    自动清空输入；
  - 数据设置页的导出路径等输入框不再**吞掉刚输入的文字**；
  - 操作日志查看器**只读最近 2000 行**（标题明确提示），打开大日志不再卡死；
    完整日志仍可"导出操作日志"或"打开文件位置"查看；
  - 从数据包恢复时，"考勤开关与同步映射"不再被错挂在"时间段"勾选项下
    （此前只勾考勤不会恢复）。
- **性能**：
  - 每次保存不再重复解密解析一遍旧数据文件（单次保存的 CPU/IO 减半，
    改一条记录更跟手）；
  - 插件界面元素与表格行数增加上限，防止手滑写出超大界面卡死；
  - 原子写失败重试耗尽后会清理临时文件（不再在文档目录堆积 `.tmp`）。

## 五、若上次装的是更早版本

从任意早于 V2.30.2 的版本升级都不需要额外步骤——直接覆盖安装即可：
- 既有操作密码**继续有效**（改密码时自动升级为更安全的格式）；
- 既有的加密插件包**继续可用**；
- 数据文件格式未变，小组/班级事件等已撤销功能的遗留字段被安全忽略。

| 版本 | 类型 | 要点 |
| --- | --- | --- |
| **V2.30.2** | 修复与加固 | 插件安全（内存/超时/保留名/解压计数/防篡改）、口令加盐多轮、数据完整性 14 项、稳定性与性能十余项 |
| V2.30.1 | 功能收窄 | 保留卡片今日角标 + 校历/日志/设置方案导出导入 |
| V2.30.0 | 新功能包 | （其中家长会/随机点名/小组/班级事件已于 V2.30.1 撤销） |

## 六、升级与回退

- **升级**：退出程序 → 运行新安装包覆盖安装 → 数据与插件自动保留，无需任何设置。
- **回退**：如遇问题，用备份文件替换 `class_management_data.enc` 即可回到升级前状态
  （程序每次启动前会自动备份一份，位于同目录的 `班级管理系统_备份\`）。
- **建议**：升级前先自行复制一份数据文件留存，最为稳妥。
