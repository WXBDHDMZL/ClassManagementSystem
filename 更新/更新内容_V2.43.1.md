# 班级管理系统 V2.43.1 更新说明

- 发布日期：2026-10-31
- 类型：权限门禁迁移 + 复合导入流程授权
- 上一版：V2.43.0+123 ｜ 本版：V2.43.1+124

## 本版做了什么

### 1. 数据层写门禁全部按动作判断

V2.42.2 只修了记录的编辑/删除；本版把数据层剩余的旧区域门禁全部迁移：

- 考勤：登记/撤销/清空/设置/导入；
- 名单与原因库：增删改、导入；
- 时段与校历：修改、导入；
- 数据：备份恢复、恢复出厂、设置方案导入；
- 记录：编辑/删除/导入、批量删除。

现在界面和数据层使用**同一个动作开关**。不会再出现：

```text
界面不要求密码 → 数据层仍按旧模块总开关拒绝
```

### 2. 复合导入流程使用显式授权作用域

一次导入会同时写多个模块，例如：

- 数据包导入：名单 + 原因库 + 时段 + 记录 + 考勤 + 校历；
- 导入记录：删除重复 + 写记录 + 补名单 + 补考勤；
- 导入考勤：补状态项 + 补名单 + 写考勤。

这些流程现在按“入口动作”验证一次，内部子写入在本次作用域内放行，避免：

- 导入到一半被另一个动作门禁拦住；
- 用户被要求连续输入多次密码；
- 只写入了部分数据却提示成功。

### 3. 旧行为仍然保留

- 管理员模式默认仍为关闭；
- 关闭管理员模式时，旧动作开关的行为保持不变，只是数据层判断改为动作级；
- 旧记录、旧备份、旧数据包不需要迁移。
