# 班级管理系统 V3.6.0 更新说明

- 发布日期：2026-11-01
- 类型：旧数据迁移验收版
- 上一版：V3.5.0+140 ｜ 本版：V3.6.0+141

## 本版目的

V3.5.0 已完成统计报表拆分。本版不新增日常功能，专门用于**在不改动现有正式数据的前提下**验证旧数据迁移链路，为后续删除旧格式兼容代码做准备。

## 改动

### 修复旧插件目录迁移条件

旧版插件可能留在 `%USERPROFILE%\Documents\班级管理系统_插件`。此前只有新插件目录不存在时才会迁移；如果程序已经创建过新目录，旧插件就永远不会被复制。

本版改为：

- 启动时显式检查一次旧插件目录；
- 新目录已存在时也复制缺失的插件文件；
- 只复制，不覆盖新目录已有文件，旧目录原样保留；
- 写入一次性标记 `.legacy_plugins_migrated`，用户删除示例插件后不会被反复复制回来。

### 旧数据保持不变

本版**不合并**旧明文 JSON 和旧自动备份中的测试/演示记录，也不改写当前正式数据：

- 当前正式库仍为 真实记录（计数已脱敏）、全班学生（人数已脱敏）、历史日期（计数已脱敏）日期、0 条考勤；
- 2026-07 的 19 条旧明文 JSON 记录保留在原文件，不导入；
- 旧自动备份中的 71 条独有测试记录保留在原备份，不导入；
- 旧插件目录、旧备份、旧日志均不删除。

### 兼容代码暂不删除

本版仍保留旧格式读取与迁移逻辑，确保用户确认迁移结果前，旧备份和旧数据包仍可被读取。确认无误后再发布删除兼容层的版本。
