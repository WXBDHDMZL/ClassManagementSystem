## 一、最重要：两个"数据安全网"漏洞已补

| 问题 | 后果 | 本版处理 |
| --- | --- | --- |
| **从备份恢复前没有等待"排队中的保存"落盘** | 恢复完的数据可能被还在队列里的旧保存**覆盖回旧值**（数据丢失） | 恢复前先 `flushPendingSaves()`（与"立即备份"同口径） |
| **保存任务的异常没有兜底** | 一旦某次保存抛错，此后**所有保存与界面刷新静默停摆**（看着正常、数据不再落盘） | 任务链加 `onError` 兜底：记录错误 + 置失败标志 + 继续工作 |

## 二、功能正确性（12 项）

- **校历导入**补齐密码门禁 + 异常捕获（此前是唯一"点坏文件没反应"的导入）；
- 内置示例插件的"考勤异常"列/角标**恢复显示**（V2.30.2 调整数据结构后它一直是空的）；
- **数据包整包还原**：记录收口到统一构造入口（超长姓名/含顿号原因会被净化）、
  考勤日期做合法性校验、旧包只有"时段标签"时不再退化成出厂时段；
- **考勤导入**校验状态值（空串与保留的"出勤"会被跳过）；
- **时段**：落库时校验（非法时段不再能通过数据包导入进来）、起止相同被拒绝、
  反查与显示统一去空格；
- **环比统计区间**改按日历运算（跨月/跨年不再错一天）；
- **校历标记**写入前校验日期与取值（非法项不再先进内存再重启丢弃）；
- **密码门禁**对未知区域改为"默认需要密码"（此前会回退到更宽松的门禁）；
- **批量删除**在"保留考勤"模式下不再漏掉无日期记录；
- 插件包清单为 GBK 编码时给出可操作提示（不再抛原始异常）。

## 三、架构与解耦（6 项）

- **导出的"保存到哪里"与列宽自适应统一到服务层**：此前记录导出与统计导出**各写一份**、
  行为已经分歧；且列宽方法住在记录列表 Widget 里、被统计模块反向调用（依赖倒置）。
  现在只有 `services/excel_export.dart` 一份实现；
- **学生卡片角标缓存迁到服务层**（原住在 widgets 里，属状态与业务）；
- **错误占位界面**从服务层迁到 widgets，改由启动处注入（服务层不再依赖 UI 组件）；
- **开发诊断代码从 `main.dart` 迁出**（生产入口不再内嵌上百行调试逻辑）；
- **学生卡片字号设置**从"考勤域"归位到"设置域"；
- **文本输入对话框**统一为 `TextPromptDialog`（由对话框自己持有并释放输入控制器，
  修掉"退场动画期间用到已释放控制器"的隐患，并消除三份重复实现）。

## 四、状态管理与性能（9 项）

- **界面刷新不再等磁盘**：改动后立即刷新界面，落盘结果再通知一次（此前要等全库加密写盘完）；
- **统计看板**只订阅"数据指纹"，无关变化不再整块重建；
- **数据指纹与总数统计加缓存**（500ms 窗口 + 数据变更即失效）：看板与设置页
  不再每次重建都全量遍历历史；
- **插件数据快照加缓存**（按指纹+参数）：装插件后每次交互不再全量扫描历史；
- **历史对话框**去掉重复订阅；**插件页**以插件注册表为唯一数据源；
- **插件视图**：参数读取与首次渲染改为串行、事件改队列（不再重复执行脚本、连点不丢事件）；
- **批量删除记录**整批只落盘一次（此前 N 条 = N 次全库加密写盘）；
- 插件角标缓存实例复用 + 签名轻量化（不再整包 JSON 序列化）；
- 名单去重、插件扫描的重复磁盘访问等小优化。

## 五、命名与可读性（11 项）

删除死代码（无引用的权限说明 getter）、修正与实现不符的注释（年份范围、
三处错误日志上下文文案、日志分块说明）、清理孤儿/悬空文档注释、
近似名方法重命名（`_sanitizeReasonList`）、`void … async` 改为 `Future<void>`、
删除不可达分支与重复间距、修正缩进、魔法数字抽为命名常量。

## 六、安全（3 项加固）

- **旧版加密插件格式（CMSJS1）停止支持**：它**没有完整性校验**（密文被改一位即可
  静默改变插件逻辑并被照常执行）。自本版起拒绝加载并提示"请用当前版本重新导出"。
  > 只影响你自己用旧版"加密导出"生成的插件包（重新导出一次即可）；明文插件不受影响。
- **插件图标路径校验**：含路径分隔符或点开头一律拒绝（防将来接线后越出插件目录）；
- **操作密码最小长度 4 → 6 位**（不影响已设置的密码，只是"改密码"时要求更长）。

## 六之二、插件能力边界（新增探针测试，实测留档）

**插件无法访问摄像头、麦克风、文件系统、网络或任何系统接口** —— 这不是"约定禁止"，
而是**环境里根本没有这些对象**。本版新增一条真实运行时探针测试逐项确认：

| 探测对象 | 实测结果 |
| --- | --- |
| `navigator` / `document` / `window`（浏览器对象，`getUserMedia` 属于这里） | **undefined** |
| `mediaDevices`（摄像头/麦克风入口） | **无** |
| `XMLHttpRequest` / `fetch` / `WebSocket`（网络） | **undefined** |
| `localStorage` | **undefined** |
| `require` / `process` / `std` / `os`（文件与系统调用） | **undefined** |
| `sendMessage`（唯一的宿主通道） | 存在，但**只被运行库内部用于 console.log/setTimeout**，程序没有注册任何接收端，调用它不会触发任何宿主行为 |

原因：插件跑在 QuickJS（**纯 JS 引擎，不是浏览器**）；宿主程序自身也从未接入任何外设代码
（全项目检索"摄像头/麦克风/剪贴板"相关实现为 0 处）。这条测试是**永久守护** ——
将来升级运行库若意外引入新对象，它会立刻失败。
