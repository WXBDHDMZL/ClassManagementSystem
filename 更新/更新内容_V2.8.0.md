# 班级管理系统 V2.8.0 更新摘要（数据安全加固 + 交互细节 + 触控适配）

- **存储格式升级（LRX2）**：数据文件改为"每份文件独立随机盐 + HMAC-SHA256 流加密 + 完整性校验"，损坏或被改动的文件会被识别出来并走备份恢复；仍可读取旧格式文件（自动兼容升级）
- **原子写入**：保存改为"先写临时文件、成功后再替换主文件"，写入中断不会留下半截主文件
- **考勤统计与校历口径统一**：统计看板/报表里的考勤异常已排除校历中标记为放假的日期（与"记录天数"同一口径，板块标题也标注"不含放假"）
- **导出与导入形成闭环**：单日/今日记录导出补上"日期"列；考勤表改为"日期/学生/时间段/状态/时间"明细（未登记学生的"出勤"行导入时自动忽略）；没有日期列的老表格按"今天"导入
- **数据包新增"整包还原（覆盖）"**：可一键用数据包内容整体替换本机数据（含时段、校历、考勤状态与同步映射），默认仍是"补充导入"
- **触控（一体机）适配**：列表与设置里的图标按钮统一 44×44 最小点按区；允许触屏/鼠标/触控板"按住拖动"滚动列表
- **导入的记录标记为"导入"**（与"追加"区分）
- **危险操作统一**：所有破坏性确认按钮（删除/清空/撤销/关闭密码/恢复出厂/整包还原）改为红色；"恢复出厂设置"移到数据页最下方
- **修改/设置密码的文案与范围说明**重写（覆盖 8 项密码开关的实际作用范围）；设置入口顺序调整（名单与原因库归入数据自定义一组）、"导出/导入"统一命名为"导出与导入"
