# 班级管理系统 V3.4.0 更新说明

- 发布日期：2026-10-31
- 类型：统计功能重构第一阶段
- 上一版：V3.3.1+136 ｜ 本版：V3.4.0+137

## 本版变更

### 1. 统计彻底移除考勤

- 统计页不再计算或展示考勤；
- 统计导出不再包含考勤工作表；
- 个人汇总单不再附加考勤明细；
- 报表默认工作表去掉 `attendance`；
- “全部记录”的起点只按表扬/批评记录计算。

考勤底层数据仍保留，供未来 DLC 使用。

### 2. 去除重复图表

- 删除折线图/柱形图/饼图的并列切换；
- 只保留一张趋势图；
- 趋势图统一展示表扬/批评随时间变化。

### 3. 趋势图可读性

- 按区间自动聚合：
  - ≤31 天按天；
  - 32–180 天按周；
  - >180 天按月；
- 横轴最多约 6 个刻度；
- 支持鼠标悬停 tooltip，显示日期、表扬数、批评数；
- 图表高度调整为 250，避免固定高度挤压；
- 支持窗口与字号变化。

### 4. 分布与排行

- 学生分布不再使用饼图；
- 继续使用横向排行条；
- 保留 Top N；
- 超出 Top N 时显示“其余 N 人未显示”；
- 删除“显示全部项目”。

### 5. 页面顺序调整

统计页顺序改为：

```text
汇总
对比与关注
趋势
排行
学生明细
```
