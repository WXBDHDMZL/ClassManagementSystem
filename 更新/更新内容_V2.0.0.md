# 班级管理系统 V2.0.0 重大更新摘要

本次从 V1.2.0 起累计的更新一并汇总为 V2.0.0：

- **桌面端能力**：系统托盘常驻（关闭行为四选一、可记住选择）、桌面悬浮球（56×56 置顶透明圆球，单击恢复、拖动记忆位置）、单实例保护、深浅色全面适配（球/托盘菜单/标题栏跟随主题）
- **设置中心改版**：入口列表 + 窗口内子页面（主题 / 窗口 / 记录 / 时间段 / 名单与原因库 / 导出与导入 / 备份与恢复 / 更新与内容包 / 安全 / 关于），切换带过渡动画
- **时间段可自定义**：可自由新增、删除、改名与调整时间范围，记录预选、显示与导出全部跟随
- **数据管理**：记录 / 名单 / 原因库 / 时间段分类导出导入 + 完整数据包；导出路径统一管理；数据备份与恢复独立成页（备份位置、频率可选、单份覆盖、按列表恢复）
- **统计增强**：对比与关注（表扬批评比、环比、需关注学生）；图表可选折线 / 柱形 / 饼图（按学生或时段占比，表扬批评可多选对比）；报表导出含四张表
- **安全体系**：可修改操作密码；密码适用范围可配置（总开关 + 名单原因库 / 时间段 / 导入与恢复 / 更新与内容包 / 恢复出厂），安全页本身也需密码进入
- **更新与内容包**：选择安装包直接更新；内容包（DLC）支持添加、启用、停用、移除（规范见《内容包制作规范》）
- **恢复出厂设置**：两次确认 + 密码校验，可一键清空数据并恢复出厂名单、原因库与设置
