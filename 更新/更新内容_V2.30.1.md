## 一、本版变化

V2.30.0 的新功能包按需求收窄：**只保留"卡片今日角标"与"导入导出完善"**，
其余新增功能全部撤销（代码已从项目中移除，`glass-attempt` 分支与 git 历史里可取回）。

### 1. 保留的功能

- **学生卡片今日角标**：左上角绿色 = 今日表扬次数，右上角红色 = 今日批评次数，
  悬浮在卡片角上、**不改变名字框的大小**；无记录时不显示；
- **导入导出完善**：
  - 校历标记导出/导入（"日期 / 类型"两列，合并导入）；
  - 操作日志导出（数据页一键另存全量日志）；
  - 错误日志导出（数据页一键另存，便于排查）；
  - 设置方案导出/导入（主题、字号、时段、校历、导出选项等一键迁移；
    **密码与各模块门禁开关不随方案迁移**）；
  - 数据包：小组与班级事件字段已同步移除，保持与旧版一致的字段结构。

### 2. 已撤销的功能（V2.30.0 引入，本版移除）

| 已撤销 | 说明 |
| --- | --- |
| 家长会模式 + 个人汇总单 | 统计看板回到原来的区间统计视图 |
| 随机点名 | 今日记录面板按钮移除 |
| 小组与小组统计 | 名单管理的小组入口、统计看板的小组筛选移除；数据层不再保存小组归属 |
| 班级事件 | 日历设置的事件管理入口、主页今日事件提示移除；数据层不再保存事件 |

> 撤销范围含数据层与数据包：`groupAssignments`/`events` 字段不再写入与读取。
> 若你曾在 V2.30.0 上使用过小组/事件，升级后这些内容不再显示（其余数据不受影响，
> 数据文件中的遗留字段会被安全忽略）。

## 四、升级与回退

- **升级**：退出程序 → 运行新安装包覆盖安装 → 数据与插件自动保留，无需任何设置。
- **回退**：如遇问题，用备份文件替换 `class_management_data.enc` 即可回到升级前状态
  （程序每次启动前会自动备份一份，位于同目录的 `班级管理系统_备份\`）。
- **建议**：升级前先自行复制一份数据文件留存，最为稳妥。
