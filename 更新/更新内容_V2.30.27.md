# 班级管理系统 V2.30.27 更新说明

- 发布日期：2026-10-04
- 类型：功能新增（最小窗口按名单自动推算）
- 上一版：V2.30.26+93 ｜ 本版：V2.30.27+94

## 本版做了什么

| 项 | 说明 |
| --- | --- |
| **学生姓名任何情况下都完整显示** | 卡片姓名不再显示省略号：正常情况下由"按名单推算的最小窗口"保证放得下；万一窗口被拖到极窄（或屏幕本身很小），姓名会**自动缩放**到刚好放下，而不是变成"张…" |
| **最小窗口大小按名单自动推算** | 程序按当前名单人数 + 姓名长度 + 卡片字号，反推出"每个姓名都能完整显示"所需的最小窗口；名单越多人、姓名越长、字号越大，最小窗口就越大 |
| **用户仍可自由放大** | 最小尺寸只是**下限**：你可以把窗口拉得更大，程序不干预 |
| **默认窗口大小 = 该最小尺寸** | 首次启动、"默认大小"启动模式下，窗口大小直接取"按名单推算出的最小尺寸"（不再是无依据的固定值） |
| **名单变化即时生效** | 增删学生、改卡片字号后，最小窗口会自动重算并下发；若当前窗口小于新下限，会先自动放大 |

### 你的名单（人数已脱敏）实测推算结果

| 卡片字号缩放 | 最小窗口尺寸 |
| --- | --- |
| 1.0（默认） | **1096 × 712** |
| 1.15 | 1176 × 712 |
| 1.4（最大） | 1538 × 696 |

（旧版固定为 1080 × 680 —— 本版略增；字号调大时会明显加大，以保证姓名放得下。）
