# 班级管理系统 V2.2.0 更新摘要（考勤重做 + 密码开关扩展）

- **考勤改为"默认全员到齐、只登记异常"**：没有登记的学生一律视为出勤，老师只需给请假、缺勤、迟到等异常学生登记，不必逐个点名
- **考勤窗口改版**：顶部显示"应到 / 实到 / 各状态人数"，中间是"登记考勤"（选学生 → 选状态 → 确认，可多选）与"导出考勤表"；下方按状态分组列出当日异常学生，每个名字后带 ×，点击可撤销该条登记（有二次确认）
- **考勤表导出**：表头写明"应到 / 实到 / 各状态人数"，并按名单顺序列出全员状态（未登记的显示"出勤"），另附登记时间
- **导出今日记录时附上当天考勤异常**（名单与状态），一天一个文件即可同时看到记录与考勤
- **状态项更明确**："出勤"是保留状态，不能作为自定义状态项；默认状态仍为 迟到 / 早退 / 请假 / 缺勤，可增删改名，改名会同步历史考勤
- **密码保护可覆盖全部数据操作**："需要密码的操作"从 5 项扩为 7 项——新增**记录**与**考勤**两个独立开关（记录不再强制要密码），连同时间段、名单与原因库、导入与恢复、更新与内容包、恢复出厂，除主题 / 窗口等不改数据的基础设置外都可单独设置是否要密码
- **内容包支持考勤状态项**：内容包（DLC）除名单、原因库、时段外，还可携带考勤状态项（《内容包制作规范》已同步更新）
- **整体性同步**：数据包与分类导入导出含考勤、导入考勤表可选择把陌生学生补进名单、学生改名同步考勤记录、启动时会修复考勤记录的重复 ID、关于页与各处说明文案补齐考勤
- 打印 / PDF 导出：按用户决定**不做**
