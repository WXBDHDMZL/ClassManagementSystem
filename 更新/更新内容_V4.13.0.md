# 班级管理系统 V4.13.0 更新说明

- 发布日期：2026-11-21
- 类型：功能新增
- 上一版：V4.12.1+174 → 本版：V4.13.0+175

## 本版目的

在原因库和时段设置中加入导入功能，便于从已有表格或文本批量录入，减少逐条添加。

## 新增内容

### 原因库导入

- 原因管理底部新增“导入原因”。
- 支持粘贴文本，或选择 `.xlsx`、`.csv`、`.txt` 文件。
- 表格列为“类型 / 时段 / 原因”；只有“类型 / 原因”两列时归入全时段通用。
- 导入前显示识别条数、表扬/批评数量与无法识别的行数，可补充到现有原因库或整体替换。
- 整体替换前会二次确认；历史记录里已保存的原因不受影响。

### 时段导入

- 时段设置新增“导入时段”。
- 支持粘贴文本，或选择 `.xlsx`、`.csv`、`.txt` 文件。
- 支持“时段 key + 标签”两列，也支持只写标签；识别后先填入时段列表，点击“保存”后生效。

## 兼容性说明

- 不改变主数据、加密、备份与日志文件格式；已有数据、备份、日志继续可用。
- 不新增运行时依赖。
- 升级只替换程序文件，不删除「文档\\班级管理系统」中的记录、名单、原因库、设置、日志或备份。
