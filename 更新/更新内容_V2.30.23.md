# 班级管理系统 V2.30.23 更新说明

- 发布日期：2026-10-04
- 类型：缺陷修复（导入与恢复一致性）
- 上一版：V2.30.22+89 ｜ 本版：V2.30.23+90

## 本版修了什么

| 问题 | 后果 | 修复 |
| --- | --- | --- |
| 表格导入勾选"覆盖重复"时，"写回记录"列表**没有去重** | 表格里同一条重复行出现两次（或两行都命中同一条现有记录）时，旧记录只删一条、却写回两条 → **库里凭空多一条重复记录** | 同一条现有记录只对应一条"覆盖写回"；重复条数计数也不再虚高 |
| 从备份恢复数据后**没有失效派生缓存**（记录/考勤计数、数据指纹） | 设置页与统计里的"总条数"仍显示**恢复前的旧值**，要等下一次真正保存才纠正 | 恢复后立即失效派生缓存，界面一次到位 |
| 数据包"补充导入"的判重键自拼为 `日期\|姓名\|类型\|时间\|原因`，**漏了"时段""备注"** | 只有"时段"或"备注"不同的记录被误判为重复，**静默丢弃**（用户看到"新增 0 条"却不知原因） | 判重键改用与表格导入**完全同口径**的统一身份串（含时段、备注） |
| 分类导入（名单/原因/时段/考勤/校历）**只读第一张工作表** | 工作簿里若有封面/说明表在前，会读错表 → "解析不到内容"（而记录导入会正确扫描各表） | 与记录导入同口径：按该类型的表头关键词在**各工作表**里挑第一张命中的；无表头的文件仍回退首张非空表 |
| 整包还原时包内名单为空，提示却写"出厂名单" | 实际行为是**保持空名单**（不回落出厂/真实名单，避免隐私外溢），提示与实际不符，误导用户 | 提示改为"空（包内未包含）" |

## 用户能感知到的变化

- 反复导入同一份表格、或勾选"覆盖重复"时，**不会再凭空多出重复记录**。
- 从备份恢复后，统计与总条数**立刻**是新数据的值。
- 数据包补充导入不再漏掉"只差时段/备注"的记录。
- 名字/原因/时段/考勤/校历表格即使工作簿里有多个工作表，也能自动选对。
- 整包还原的完成提示与实际结果一致。
