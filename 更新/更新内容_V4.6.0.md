# 班级管理系统 V4.6.0 更新说明

- 发布日期：2026-11-07
- 类型：功能增强版（非破坏性）
- 上一版：V4.5.1+151 → 本版：V4.6.0+152

## 本版目的

增强桌面悬浮球的日常使用体验：在右键菜单中补充今日记录摘要，并增加位置锁定与贴边自动隐藏，减少误拖和遮挡。本版不改变主数据、加密格式、备份格式与考勤门控。

## 新增功能

- **今日摘要**：右键菜单的“今日概览”顶部显示“今日：表扬 X · 批评 Y”，不用打开主窗口即可了解当天记录数量。
- **锁定位置**：右键菜单和设置 → 外观与窗口都可开启；开启后左键拖动不会移动悬浮球，避免误触。
- **贴边自动隐藏**：右键菜单和设置 → 外观与窗口都可开启；把球拖到屏幕边缘松手后只保留一条窄边，鼠标移入或按下即可恢复完整悬浮球。

## 交互说明

- 今日摘要随记录变化实时更新，跨天后自动切换为当天的统计。
- 锁定位置后仍可正常单击球恢复主窗口；拖动尝试不会触发误操作。
- 贴边自动隐藏后记住的是完整位置，下次启动仍从可见位置出现。
- 关闭贴边自动隐藏时，如果球正处于贴边状态会立即恢复。
- 原有左键单击、左键拖动、右键菜单、不透明度调整、收起到托盘等操作保持不变。

## 兼容性说明

- 主数据、加密、备份、恢复流程不变，V4.5.1 数据可直接升级；
- 旧设置缺少“锁定位置”“贴边自动隐藏”字段时按关闭处理，不影响旧版本使用；
- 本版不删除 `文档\班级管理系统\` 下的数据，升级安装只替换程序文件；
- 不新增外部依赖，不改变安装目录结构。
