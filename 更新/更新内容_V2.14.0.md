# 班级管理系统 V2.14.0 更新摘要（插件系统第一批：能装、能管、能跑）

- **"内容包"正式变成"插件"**：设置里的「更新与内容包」改为「更新与插件」，内容包那套已移除（旧的 `.json` 内容包不再支持）
- **插件长什么样**（每个插件一个文件夹）：
  ```
  文档\班级管理系统_插件\
    └─ example.attention-list\
         ├─ plugin.json   清单：名字/版本/作者/要哪些权限
         └─ main.js       逻辑（JavaScript）
  ```
- **设置 → 更新与插件** 里可以直接：**导入插件包（.zip）**、**一键创建示例插件**、**打开插件文件夹**、**启用 / 停用**、**试跑（用本周真实数据）**
- **权限明示**：插件申请了哪些能力会逐条用中文列出（读统计数据 / 读名单 / 写入记录（需确认）/ 注册报表 / 自己的页面 / 自由画布 / 写日志），装之前就能看清
- **安全**：插件在**隔离环境**里运行、**超时直接强杀**（插件写死循环也卡不死程序）；拿不到网络、文件和数据库；想改写数据只能在返回值里提"写入意图"，由程序弹确认框后执行
- **自带示例插件**「示例：需关注学生清单」：读本周统计、把批评达到阈值的学生列出来；改 `main.js` 顶部的 `threshold = 3` 就能改规则，点"试跑"立刻看到结果
