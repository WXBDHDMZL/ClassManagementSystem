# 班级管理系统 V1.0.0（一周年纪念版）更新说明

- 发布日期：2026-08-28
- 类型：从网页版迁移到 Windows 桌面端的首个正式版
- 上一版：原 HTML 网页版（浏览器 localStorage） ｜ 本版：V1.0.0

## 本版定位

V1.0.0 是“一周年纪念版”，也是班级管理系统从**原 HTML 网页版**迁移到 **Windows 桌面程序**的第一个正式版本。它不是把网页套进桌面窗口，而是把运行方式、数据存储、记录模型和界面布局整体重做。

## 对照原 HTML 版的主要变化

| 维度 | 原 HTML 网页版 | V1.0.0 电脑版 |
| --- | --- | --- |
| 运行方式 | 用浏览器打开 HTML 文件，依赖浏览器环境 | 独立 Windows 程序，双击桌面图标打开，不需要浏览器、不需要联网 |
| 安装与入口 | 浏览器收藏/本地文件 | 提供安装包，安装后生成桌面与开始菜单快捷方式 |
| 数据存储 | 浏览器 `localStorage`，清理浏览器缓存可能丢失 | 加密保存在电脑“文档”目录的 `class_management_data.enc`，清理浏览器不影响数据 |
| 记录语义 | 用 `add` / `deduct` 表示加/扣分 | 改为“表扬 / 批评”记录，带原因、备注、时间段与记录时间 |
| 考勤 | 网页版自带请假/缺勤/出勤标记 | V1.0.0 暂未提供考勤模块；考勤在 V2.1.0 重新加入 |
| 时段 | 上午/下午上课分开，早/中/晚饭分开 | 电脑版内置 12 个在校时段；V1.1.0 起合并为 9 段 |
| 界面 | 浏览器页面 | 左侧学生卡片网格 + 右侧今日记录常驻面板，窗口可缩放 |
| 导出 | 网页内导出 Excel/CSV，列格式与电脑版不同 | 导出今日记录、按日期/合并/分别导出，以及表扬/批评排名表 |
| 操作保护 | 网页版本地文件无系统级入口保护 | 编辑、删除、追加记录需密码确认 |
| 数据迁移 | 数据在浏览器里 | V1.0.0 不自动读取网页版 `localStorage`；网页版旧数据请先保留，后续版本提供迁移工具 |

## 本版新增与保留的能力

### 1. 快速记录与今日总览

- 点击学生卡片即可记录表扬或批评，按当前时刻自动预选时段。
- 内置 12 个在校时段，原因一键多选，支持自定义原因与备注。
- 右侧面板实时展示今日记录，表扬、批评、追加用不同语义色区分。

### 2. 历史与 Excel 导出

- 支持多日期查询、跨日期“选中之间”补齐、事后追加记录。
- 支持导出今日记录、按日期导出、合并导出、分别导出，以及表扬/批评次数排名表。

### 3. 桌面端体验

- 浅色 / 深色 / 跟随系统三态主题，Material 3 配色，切换实时生效并持久化。
- 学生卡片与文字随窗口尺寸自动调整，窗口有最小尺寸限制。
- 数据只存本机，不收集、不上传。

### 4. 工程与构建

- Flutter + Provider + Excel 导出，Windows 桌面 Release 构建。
- 提供安装包脚本与程序内用户条款。

## 升级与回退

- 首次使用直接安装；从网页版迁移时，不要清理浏览器中的网页版数据。
- V1.0.0 不能自动导入网页版 `localStorage`；后续版本提供网页版导出与迁移工具。
- 回退到网页版不影响电脑版数据；两套数据相互独立。
