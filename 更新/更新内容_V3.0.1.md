# 班级管理系统 V3.0.1 更新说明

- 发布日期：2026-10-31
- 类型：清理旧“操作密码”残留，统一为管理密码
- 上一版：V3.0.0+127 ｜ 本版：V3.0.1+128

## 本版修复

### 1. 安全设置不再要求“操作密码”

V3.0.0 已删除旧操作权限页面，但“安全与密码”入口仍在走旧密码路径。

V3.0.1 起：

- 打开「安全与密码」统一要求进入管理员模式；
- 密码框标题/标签统一显示「管理密码」；
- 不再显示“请输入操作密码”。

### 2. 安全页合并为一个管理密码

「安全与密码」页面不再展示：

- 操作密码 / 班主任密码双密码模式；
- 独立、合并、优先等密码模式；
- 两套密码互相重置入口。

现在只保留一个「管理密码」：

- 用于进入管理员模式、打开安全设置；
- 支持设置、修改、关闭；
- 忘记时用恢复码重置；
- 恢复码文案也改为“重置管理密码”。

### 3. 所有敏感操作提示统一

旧提示“请先输入操作密码”已全部替换为：

```text
请先进入管理员模式
```

包括：考勤、名单、原因、时段、校历、数据包、备份恢复、插件、更新等。

### 4. 界面文案与历史记录高亮修复

- 「选择记录人」只保留操作指引：请选择本次操作使用的记录人；
- 移除“不需要密码”“管理员模式由密码入口控制”等设计/更新解释；
- 历史记录日期多选改为有边界的选中底色，避免高亮溢出到上一行；
- 新增 UI 文案守护测试，禁止功能界面出现更新说明/旧版表述。

### 5. 班主任记录人选择不需要密码是预期行为

V3 的“记录人”只做署名，不再承担权限。

- 选择班主任记录人不需要密码；
- 进入管理员模式才需要管理密码；
- 管理密码保护的是修改他人记录、导入、设置等敏感操作。

这不是漏验证，是 A+C 权限模型的设计。

## 兼容说明

- 旧数据字段仍可读取；
- 旧操作密码/班主任密码哈希不会删除；
- 统一验证时优先使用现有管理密码哈希；
- 旧密码模式字段不再展示，也不再参与新权限判断。
