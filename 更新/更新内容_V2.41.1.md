# 班级管理系统 V2.41.1 更新说明

- 发布日期：2026-10-24
- 类型：页面验证与动作权限解耦、密码模式切换修复
- 上一版：V2.41.0+118 ｜ 本版：V2.41.1+119

## 本版改了什么

### 1. 关闭页面验证后，打开页面不再要求密码

- 之前“进入页面时验证”关闭后，页面内的“修改考勤设置/名单/校历”等动作规则仍会在打开页面时弹密码。
- 现在页面开关只控制**打开页面时是否验证**：
  - 页面开关关闭：可直接进入页面；
  - 页面开关开启：进入页面时验证一次；
  - 页面内的修改、保存、删除、导入：仍按对应动作开关在真正执行时验证。
- 两套开关互不代替。想连修改也免密，需要把对应动作开关也关闭。

### 2. 页面内动作验证放到真正执行时

以下操作不再靠“进页面”间接保护，而是在执行时按动作规则验证：

- 考勤设置：启用考勤、增删改状态、同步原因、恢复默认；
- 时间段：保存、删除、恢复默认；
- 校历：添加/删除标记、粘贴导入；
- 名单与原因库：打开名单管理、原因管理；
- 插件：导入、创建示例/演示、启用/停用、删除。

记录、考勤登记、数据包、备份恢复、日志清理、更新、恢复出厂等原有动作门禁保持不变。

### 3. 密码模式切换后不再残留浅色遮罩

- 密码模式选择从下拉菜单改为 4 个按钮，避免下拉菜单路由与后续“设置班主任密码”对话框叠加，留下点不掉的遮罩。
- 切换模式并在合并模式下首次设置班主任密码时，对话框标题正确显示“设置班主任密码”，不再显示成“设置操作密码”。

### 4. 回归测试

- 新增密码模式切换的界面回归测试：完成设置后无残留遮罩、无对话框、模式正确切换。
- 新增页面开关与动作规则独立性的模型测试。
- 导出测试等待文件句柄释放，降低 Windows 上杀软/索引器短暂占用导致的偶发失败。

## 升级与回退

- 覆盖安装即可；V2.41.0 的动作规则与页面开关设置继续保留，不需要重新配置。
- 如果之前打开了页面验证又觉得重复弹窗，现在可以只保留页面验证或只保留动作验证其中一层。
- 回退到 V2.41.0：重装旧安装包即可；页面开关会恢复为旧版“与动作规则叠加”的行为，回退前建议先记录当前操作权限设置。
