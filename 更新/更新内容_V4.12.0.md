# 班级管理系统 V4.12.0 更新说明

- 发布日期：2026-11-21
- 类型：功能新增
- 上一版：V4.11.0+172 → 本版：V4.12.0+173

## 本版目的

让名单可以从常见的表格、文本和 Word 文件中一次导入，不再需要逐条输入。

## 新增内容

### 名单导入

- 「设置 → 记录与名单 → 名单与原因库 → 名单管理」新增“导入名单”入口；设置里的“导入名单”也使用同一套流程。
- 支持两种来源：
  - 粘贴文本：每行一个姓名，也可以用逗号、顿号、分号分隔，或直接粘贴 Excel 的单元格区域。
  - 选择文件：支持 `.xlsx`、`.csv`、`.txt`、`.docx`；`.xls` 旧格式需另存为 `.xlsx` 后再导入。
- 自动识别“姓名 / 学生姓名 / 名字 / 学生”列；没有表头时，如果首列是序号，则读取第二列。
- 自动跳过空行、序号、重复姓名和不合法的姓名，并在预览区显示识别人数、重复数量、已在名单中的人数和被跳过的姓名。
- 预览确认后，可以选择“补充到名单”（只添加缺少的学生）或“替换现有名单”（二次确认后替换）。
- 导入只改名单，不删除历史记录。

### 文本文件编码

- `.txt` 支持 UTF-8 和带 BOM 的 UTF-16；不是 UTF-8 的文本会提示另存为 UTF-8。

### Word 文件

- `.docx` 读取正文中的段落和表格；表格中有“姓名”列时按该列读取，没有表头时按第一列读取。

## 兼容性说明

- 不改变主数据、加密、备份与日志文件格式；已有数据、备份、日志继续可用。
- 新增依赖 `archive` 与 `xml`，只用于读取 `.docx`，不联网、不改动已有文件。
- 升级只替换程序文件，不删除「文档\\班级管理系统」中的记录、名单、原因库、设置、日志或备份。
