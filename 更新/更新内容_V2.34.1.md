# 班级管理系统 V2.34.1 更新说明

- 发布日期：2026-10-17
- 类型：修复与一致性完善（记录身份、考勤同步、批量归属日、程序内更新）
- 上一版：V2.34.0+109 ｜ 本版：V2.34.1+110

## 本版改了什么

### 1. 记录身份与操作密码

- 身份闲置退出改为“固定基础时限 + 最后一分钟顺延”：基础时长内触摸不会重新计时；
  进入最后 1 分钟后，每次触摸把退出时间推到该次操作之后 1 分钟。
- 未设置操作密码时，进入身份管理或选择班主任身份只提示先设密码，不再弹出无密码
  可输的验证框；记录身份开启时，关闭操作密码会被阻止并提示先关闭身份。
- 如果升级前已处于“身份开着但没有密码”的状态，可直接从提示框关闭记录身份；
  身份列表与历史记录人不会被清空。
- 设置方案导入、备份恢复与恢复出厂会同步当前记录身份；本机未启用操作密码时，
  设置方案不会启用记录身份。
- 启用记录身份后，新增、批量记录与考勤登记前都要先选择记录人；考勤窗口在未选
  身份时先弹出身份选择，取消则不会打开。
- 表扬/批评只剩一种启用时，最后一个开关置灰；选择“不自动退出”时，班主任退出
  开关置灰并说明暂不生效。

### 2. 记录与考勤一致性

- 「批评」记录类型停用时，登记考勤不再新生成同步批评记录；已有同步记录仍会随
  考勤修改或撤销一起更新，重新启用“批评”后恢复生成。考勤设置页会显示对应说明。
- 主界面「批量」入口改为按所选时段的归属日写入（凌晨就寝归前一天），与单条记录、
  考勤的默认日期一致；历史页按明确日期补录不受影响。
- 表格导入识别“记录人”列，导出后再导入不会丢失记录人。
- 设置方案兼容旧文件缺少新字段的情况，并保留本机路径、开机启动项、上次备份/
  自动导出时间等本机状态；备份恢复与恢复出厂后会同步开机启动注册表。

### 3. 界面与说明

- 取消「学生卡片字号」调节设置项；卡片字号继续随卡片尺寸自动缩放。旧数据中的
  该字段会自动忽略，不影响启动与已有设置。
- 设置首页的密码摘要改为“数据操作免密”，并说明进入安全设置仍需验证出厂默认密码。
- 修正与实现不一致的说明：备份实际自动保留最近 10 份；关闭密码后安全入口仍需
  出厂密码；设置方案不迁移本机路径；补齐 README 的当前功能、默认原因排序、
  统计报表、需关注阈值、开机启动目标与悬浮球透明度等描述。
- README、关于页与服务条款补充天气联网说明：天气查询仅发送所选地区名称或坐标，
  不上传班级数据；条款版本更新为 V3.1.1。
- 真机验证清单补充天气、记录身份、批量记录与程序内更新的手工检查项。

### 4. 程序内更新

- 在程序内选择更新包后自动静默安装，不再显示安装向导的“下一步”；程序会先等
  本程序完全退出，避免文件占用导致更新失败。
- 安装成功后由更新助手主动重新打开程序；不再依赖安装包的静默启动项。
- 修复部分系统上更新助手未执行、程序关闭后没有后续的问题；助手现在会等安装程序
  结束并确认退出码后再重启程序。
- 安装失败、取消 Windows 管理员授权或更新助手出错时，会尝试重新打开原程序，
  并弹出提示说明失败原因；日志仍写入 `%TEMP%\班级管理系统_更新日志.txt`。
- MSI 安装返回 3010（需要重启）时按安装成功处理，不再误判为失败。
- 手动双击安装包仍显示正常安装向导，两种更新方式互不影响。
- 静默安装仍需 Windows 管理员授权提示（UAC），这一步无法由程序跳过。

### 5. 说明

- 身份**不是登录账号**，班干部身份是自报的，程序无法防止冒用；
  真正的安全边界仍然只有班主任的操作密码（用于身份切换和敏感设置）。
- 关闭“记录身份”不会清空身份列表、历史记录人和导出数据。

## 升级与回退

- 覆盖安装即可；旧数据缺少身份或新设置字段时按默认值处理，不影响已有数据。
- 回退到 V2.34.0：重装旧安装包即可；记录人字段与新设置字段会保留在数据文件里，
  不影响旧版使用。
