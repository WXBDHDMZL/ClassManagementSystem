# 班级管理系统 V2.32.1 更新说明

- 发布日期：2026-10-17
- 类型：外观调整（按使用者要求取消液态玻璃）
- 上一版：V2.32.0+104 ｜ 本版：V2.32.1+105

## 本版改了什么

**一句话**：悬浮球取消全部液态玻璃效果，改成普通半透明圆球。

具体：

1. 移除折射、色散、两档模糊、边缘高光、左上高光、内侧反光、周圈暗边、厚度阴影、极细噪点、底部投影。
2. 移除呼吸浮动、高光游走和按下压扁/回弹动画。
3. 球体现在是"主题色半透明圆底 + 图标"：浅色主题近白、深色主题深灰，整体透明度继续由设置里的不透明度滑块控制。
4. 原有的半透明开关保留：开启时更透，关闭时更接近纯色球。
5. **实时性不变、而且更彻底**：半透明由系统合成器每帧与桌面实时混合，不需要再截图、采样或自己重建背景，因此不会再出现停在旧画面、闪烁或补采样的延迟；静止时也几乎不耗 CPU。
6. 拖拽、位置记忆、单击打开主界面、DPI 自适应、圆外点击穿透全部保持不变。

之前的液态玻璃版本仍保留在 git 历史中（V2.32.0，提交 `8cc0e51`），需要时可以恢复。
