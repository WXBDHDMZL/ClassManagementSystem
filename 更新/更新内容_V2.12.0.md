# 班级管理系统 V2.12.0 更新摘要（悬浮球改成"液态玻璃"质感）

- **悬浮球不再是不透明的实心圆**：现在会**采集小球下方的桌面内容、做模糊后透出来**，再叠一层跟随主题的薄雾底色，看起来就像一块磨砂玻璃浮在桌面上
- **玻璃质感细节**：左上有柔和高光、底部有内阴影（球有厚度、不像贴纸）、边缘有一圈"左上亮、右下暗"的反光描边
- **新增两个外观设置**（设置 → 界面外观 → **悬浮球外观**）：
  - **磨砂玻璃效果**开关：关掉就退回原来的纯色小球（觉得卡或不喜欢可以随时关）
  - **不透明度**滑块（35%–100%，默认 88%）：想让球更透或更实，自己拖就行
- **性能上的取舍**：拖动小球的过程中用纯半透明底（避免背景错位发虚），**松手停下后立刻重新采集背景**，所以停下就是清晰的玻璃效果
