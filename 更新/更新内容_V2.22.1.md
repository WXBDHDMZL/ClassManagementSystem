# 班级管理系统 V2.22.1 更新摘要（修复：设置子页内容溢出面板）

- **修复**：设置子页（记录 / 导出与导入 / 关于 / 更新与插件等）内容超出面板可视范围，**直接画到面板外面**——看起来就是"没渲染到的位置却有内容"
- **原因**：V2.22.0 给首页列表加"记住滚动位置"时，把子页面原本的**滚动包裹**弄丢了：子页内容不再可滚动，超出部分原样溢出
- **改法**：恢复子页的滚动包裹（首页的滚动位置记忆不受影响）
- **补上面板级回归测试**：用贴近真实窗口的小视口打开面板、进入子页、断言无布局异常且能滚动到页尾；**实测把修复回退后该测试立刻失败**（报 `RenderFlex overflowed by 126 pixels`），能拦住这个问题
