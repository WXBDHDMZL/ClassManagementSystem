# 班级管理系统 V2.30.32 更新说明

- 发布日期：2026-10-04
- 类型：缺陷修复（清理剩余问题清单中"仍未修"的 16 项）
- 上一版：V2.30.31+98 ｜ 本版：V2.30.32+99

> 本版是前 10 轮修复计划之后的"清残余"：把外部审查清单里**仍未修**的条目一次清掉。

## 本版修了什么

### 一、数据正确性

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| **G-3** | `addRecord` 对 date 零校验：导入/插件传入 `2026-99-99` 会生成永不命中的**脏桶键**；注入的 recordId 不查重会撞号 | 日期非法时**回退到归属日**；recordId 已存在则自动换新 id |
| **G-31** | 表格导入年份上界 9999，却与下游 2100 不一致 —— 2101+ 能过预览（"可导入 N 条"）后被**静默丢弃** | 上游上界收紧为 2100（与下游同一常量） |
| **G-34** | 校历导入用 `add(Duration(days:1))` 推进日期，夏令时时区遇 25 小时日会**同一天写两次** | 改为日历进位 `DateTime(y,m,d+1)`（与统计侧同口径） |

### 二、功能静默失效

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| **G-15** | 出厂原因库缺"早退"，而出厂同步映射引用它 —— 新装用户同步生成的"早退"批评记录，原因**在记录对话框里选不到** | 批评原因库 `_common` 补上"早退" |
| **G-24** | 内置示例插件 `renderExportSheets` 仍读已删除的 `student.attendance` —— 导出表"考勤异常"列**恒为空**，还示范了错误写法 | 改读顶层 `attendance.byStudent` |
| **G-39** | 数据包导入时，校历/每周起始日/考勤开关/同步映射**无条件恢复** —— 只勾"学生名单"也会悄悄改动设置 | 新增"校历与考勤设置"勾选项，不勾则完全不动 |
| **G-42** | 考勤状态项为空时点"确认登记"会 `pop(null)` 被当成取消，**用户以为登记成功** | 未选中状态时"确认登记"置灰 |

### 三、提示与可见性

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| **G-29** | 原因库导入时无法识别的行**静默丢弃、毫无反馈** | 统计跳过行数并在对话框如实提示"有 N 行无法识别" |
| **N-4** | 替换名单为全空时静默 no-op，无任何反馈 | 返回失败并在界面提示"名单为空，未做替换" |
| **G-19** | 时段全局状态不随测试重置，测试间可串态 | 新增 `resetPeriodsForTest()`（测试基建） |

### 四、本机路径隔离与去重

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| **G-30** | 设置方案"剥离清单"导出/导入两处维护且**不对称**（导入侧漏 3 个路径键）——旧文件仍能在 B 机凭空建目录 | 抽成共享常量 `strippedSettingKeys`，两端共用 |
| **G-28** | 记录导出列宽自适应是旧慢实现（`text.split('')`）且与另一份**开始漂移** | 改调服务层 `ExcelExport.autoFitColumns`（唯一实现） |
| **N-3** | 保存同步映射时先 `_save()`，批次内补原因再 `_save()` → 补了新原因时**两次全库写盘** | 合并为批次末尾一次落盘 |

### 五、界面健壮性

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| **G-45** | 学生明细一次性全量构建进 Column（"全部记录"区间可达数百条） | 改定高 `ListView.builder` 懒加载 |
| **G-46** | 明细行时段名逻辑与记录列表不一致且疑似颠倒（可能显示 `custom_17xxxxx` 机器串） | 统一改调 `periodNameForRecord` |
| **G-48** | 设置面板等 5 处对话框固定宽未 clamp，窗口拖小会**横向溢出** | 统一 `clampDialogWidth/clampDialogHeight` |
| **G-49** | 导入记录对话框未设 `scrollable`，名单缺失很长时**竖向溢出** | 开启 `scrollable: true` |
