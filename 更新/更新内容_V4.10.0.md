# 班级管理系统 V4.10.0 更新说明

- 发布日期：2026-11-15
- 类型：界面调整（关于页整合版本与更新）
- 上一版：V4.9.8+170 → 本版：V4.10.0+171

## 本版目的

把版本信息、检查更新与项目信息集中到「关于」页，减少维护页里的功能入口；启动时可以自动检查一次正式发布版本。

## 调整内容

### 关于页

- 「设置 → 关于」新增“版本”分组：显示当前应用版本，并提供“启动时检查更新”开关（默认开启）。
- 关于页内可直接“检查更新”：读取 GitHub 上的正式发布版本，有可用版本时显示版本号、安装包大小与发布说明，确认后下载并安装。
- 检查更新与安装前的验证只要求输入管理密码，不再要求先选择操作身份。
- 下载后优先按 GitHub 提供的 SHA-256 摘要校验；没有摘要时读取同名 `.sha256` 文件校验。校验不通过会删除文件并提示。
- 关于页新增“项目”分组：项目地址可点击打开公开仓库，并显示开源许可证、开发作者与版权声明。
- 原「设置 → 系统与安全 → 日志与维护 → 程序更新」入口已移除；不再提供“选择本地安装包”，更新统一从关于页检查 GitHub 正式版本。

### 启动检查

- 开启“启动时检查更新”后，程序启动时在后台检查一次 GitHub 正式发布版本。
- 检查不弹窗、不阻塞启动；发现可用版本时在关于页显示提示。检查失败不影响正常使用。
- 该开关保存在设置中；旧数据没有该字段时按开启处理。

## 兼容性说明

- 不改变主数据、加密、备份与日志文件格式；已有数据、备份、日志继续可用。
- 不改变记录、名单、统计、导出、备份恢复等其他功能。
- 升级只替换程序文件，不删除「文档\\班级管理系统」中的记录、名单、原因库、设置、日志或备份。
