# 班级管理系统 V2.1.0 更新摘要（考勤）

- **新增考勤功能**（可在设置中开关，默认关闭）：记录列表底部新增"考勤"入口，按日期登记学生考勤
- **考勤状态可自定义**：默认"迟到 / 早退 / 请假 / 缺勤"，可在"设置 → 考勤"里新增、改名、删除；改名会同步更新已有考勤记录，删除后仍使用该状态的记录显示为"已停用"，可再改名恢复
- **考勤纳入数据管理**：分类导出 / 导入新增"考勤记录"（日期 / 学生姓名 / 考勤状态三列）；一键导出的数据包与完整恢复也包含考勤与考勤状态
- 考勤数据随"恢复出厂设置"一并清空；学生改名时历史考勤记录同步更新
- V2.2.0 已把登记方式改为"默认全员到齐、只登记请假缺勤等异常"
