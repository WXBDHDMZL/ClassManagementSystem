# 班级管理系统 V2.30.17 更新内容

> 对比版本 V2.30.16 · 类型：第四梯队（性能）G-38 全部完成

## G-38：所有滑块改为"拖动只预览、松手才提交"

新增共享组件 `CommitSlider`，覆盖全部 6 个滑块（需关注阈值 3 个 + 卡片字号 + 排行条数 + 悬浮球透明度）。
此前拖动滑块时 onChanged 逐 tick 写 provider，一次拖动触发几十次全库加密写盘与全界面重建；现在松手才提交一次。

| 滑块 | 位置 |
| --- | --- |
| 需关注阈值（周/月/学期） | 记录页 |
| 排行显示条数 | 记录页 |
| 学生卡片字号 | 主题页 |
| 悬浮球不透明度 | 窗口页 |

验证：静态分析 0 告警 / 全量测试 414 项全绿 / exe 构建成功（2.30.17+84）。
