# 班级管理系统 V2.43.0 更新说明

- 发布日期：2026-10-31
- 类型：身份与权限第一阶段（管理员模式 + 本人编辑窗口）
- 上一版：V2.42.2+122 ｜ 本版：V2.43.0+123

## 本版做了什么

把“记录人署名”和“修改权限”拆开：

```text
记录人：只署名，不再需要密码
管理员模式：输一次班主任密码，保持 15 分钟
本人编辑窗口：创建后 10 分钟内可改删自己的记录
```

### 1. 记录人只做署名

- 启用“管理员模式”后，选择班主任记录人不再要求密码；
- 记录人仍写入每条新增记录；
- 记录人只决定“这条记录是谁登记的”，不决定能改谁。

### 2. 管理员模式

- 右上角出现管理员模式入口（锁图标）；
- 输入班主任密码后可进入，默认保持 15 分钟；
- 修改/删除他人记录、导入、设置等敏感操作统一使用管理员模式；
- 管理员模式只存在内存中：重启、超时、手动退出即失效；
- 进入/退出会写入操作日志。

### 3. 本人编辑窗口

- 新建记录会保存创建者身份 ID 和创建时间；
- 记录人可在默认 10 分钟内改删自己创建的记录；
- 超过窗口、修改他人记录 → 需要管理员模式；
- 旧记录没有创建者信息 → 只能管理员模式处理，不按姓名猜测；
- 导入/插件等没有个人所有者的记录 → 只能管理员模式处理。

### 4. 与旧操作权限的关系

旧“操作权限”页面的动作开关继续保留，在管理员模式下语义变为：

```text
动作开启 = 执行前需要进入管理员模式
动作关闭 = 普通模式可直接执行
```

“编辑/删除记录”固定按“本人窗口 / 管理员模式”判断，不再受旧开关影响。

## 如何启用

默认关闭，避免升级后突然改变全校操作习惯：

1. 打开「设置 → 记录身份」；
2. 打开「启用管理员模式」；
3. 按需调整管理员模式时长、本人编辑窗口；
4. 用学生身份新增、修改、删除自己的记录验证；
5. 再验证修改他人记录会要求管理员模式。

关闭开关即可回退到 V2.42.2 的身份/权限行为。

## 本阶段边界

- 管理员模式默认关闭，需要手动启用；
- 旧记录没有创建者 ID，不能使用本人窗口；
- 复合导入/恢复流程仍沿用旧会话逻辑，没有在本次一并重构；
- 每个身份的 `allowSelfEdit` 字段已加入数据模型，但暂未在设置页逐项开放；
- 未实现按角色细分权限（教师/班干部/学生矩阵）。

## 升级与回退

- 覆盖安装即可，不需要重新输入密码；
- 新增字段对旧数据是可选的，旧记录不受影响；
- 关闭“启用管理员模式”可立即回退旧行为；
- 回退到 V2.42.2 时，本版新增的设置字段会被旧版本忽略。
