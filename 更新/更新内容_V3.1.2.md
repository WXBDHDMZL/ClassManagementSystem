# 班级管理系统 V3.1.2 更新说明

- 发布日期：2026-10-31
- 类型：权限旧代码清理（第二批）
- 上一版：V3.1.1+130 ｜ 本版：V3.1.2+131

## 本版清理

### 1. 清理旧权限 API

已删除确认无运行调用方的旧接口：

- `passwordRequiredForAction`
- `passwordRequiredForPage`
- `setPasswordActionEnabled`
- `setPasswordPageGateEnabled`
- `setPasswordReverifyMode`
- `currentPasswordPreset`
- `applyPasswordPreset`
- `AuthService.securityPageCredential`
- `PasswordPromptDialog.allowFactoryDefault` 及其不可达分支

### 2. 清理旧页面/预设配置

已删除：

- `PasswordPage`
- `PasswordPreset`
- `PasswordReverifyMode`
- `AppSettings.passwordPageGates`
- `AppSettings.passwordReverifyMode`
- `AppSettings.managementModeEnabled`
- `AppSettings.headTeacherIdleExit`

旧数据里如果还带这些字段，会被直接忽略；不再写入新数据。

### 3. 清理旧界面文案

- 备份设置不再写“两套密码、密码模式”；
- 从备份恢复不再提示“旧版备份按合并模式处理”；
- 恢复码文案由“管理密码均改为”修正为“管理密码已改为”；
- 操作身份说明中的“班主任密码”改为“管理密码”；
- 密码框默认标签由“操作密码”改为“管理密码”。

### 4. 扩展 UI 文案守护测试

功能界面文案测试现在：

- 同时扫描 `lib/main.dart` 与全部 `lib/widgets`；
- 新增禁止词：两套密码、密码模式、旧版备份、管理员模式、操作密码、记录身份；
- 继续禁止更新日志、旧版对比、迁移说明、设计解释进入功能文案。

### 5. 清理旧测试

- 删除已失效的 `password_policy_test.dart`；
- 删除 `attendance_test.dart` 中旧的区域密码策略测试组；
- 删除 `v230_audit_p1_test.dart` 中旧分项密码开关测试组；
- 重命名旧命名的测试文件：
  - `management_mode_test.dart` → `operation_identity_permissions_test.dart`
  - `identity_password_consistency_test.dart` → `operation_identity_auth_test.dart`
  - `record_password_flow_test.dart` → `record_management_flow_test.dart`
  - `password_relation_test.dart` → `legacy_password_compat_test.dart`
