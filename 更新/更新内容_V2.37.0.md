# 班级管理系统 V2.37.0 更新说明

- 发布日期：2026-10-24
- 类型：忘记密码找回（恢复码 + 本机离线工具）
- 上一版：V2.36.0+113 ｜ 本版：V2.37.0+114

## 本版改了什么

### 1. 密码找回：一次性恢复码

- 「设置 → 安全与密码」新增“密码找回”分组，可生成或关闭恢复码。
- 恢复码为随机 20 位、分组显示，只在生成时展示一次；本机只保存加盐哈希，不保存明文，也不上传。
- 忘记密码时，在密码输入框点「忘记密码」，输入恢复码即可把操作密码与班主任密码重置为同一个新密码，并清除锁定状态。
- 恢复码成功使用后立即作废，需要重新生成；生成新恢复码会替换旧码。
- 恢复码尝试同样受连续失败锁定保护；未设置恢复码时明确提示不可用，不会像未启用密码那样直接放行。
- 导出设置方案时会剥离恢复码哈希，不会随方案泄露。

### 2. 本机离线找回工具

- 新增 `tools/local_recovery` 离线工具，不进入安装包、不随软件分发。
- 用于忘记密码且恢复码也未保存的情况：先备份主数据与锁定文件，再重置两套密码，支持 `--dry-run` 预演。
- 工具只在本机运行，不内置到程序，也不提供运行时后门。

### 3. 安全边界

- 恢复码只保存在本机加密数据文件中；恢复码明文不写入日志、设置方案或数据包。
- 离线工具只用于本机维护，正式程序内不存在免密入口。

## 升级与回退

- 覆盖安装即可；旧数据没有恢复码字段时按“未设置”处理，不影响原有密码。
- 回退到 V2.36.0：重装旧安装包即可；已设置的恢复码会被旧版忽略，原密码不受影响。
- 恢复码请抄写或打印后单独保存；恢复码与密码同时丢失时，只能使用本机离线工具。
