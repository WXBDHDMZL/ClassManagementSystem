# 班级管理系统 V2.16.0 更新摘要（插件能"写数据"了：写入意图 + 用户确认）

- **插件自己依然不能改数据**：它只能在返回值里提"写入意图"（写谁、哪个时段、表扬还是批评、原因），程序**逐条列出来弹确认框**，你点了才真正写入
- **三道闸门**：
  1. 插件必须声明 `writeRecords` 权限，否则全部忽略并在结果里提示
  2. **名字不在当前名单里的条目逐条忽略**（宁可少写，不可写错），并在确认框里告知忽略了几条
  3. 点"取消"则一条都不写，插件不留下任何改动
- 确认框的写入按钮用**警示色**，按钮上直接写着"确认写入 N 条"
- 写入的记录来源标记为"插件写入"，并写进操作日志，方便回溯是谁写的
- 插件的输入数据里补上了**时段 key**（`periods[].key`），插件回填时不会写错时段
- 《插件开发规范》同步更新：完整的写入示例 + 四条硬性规则
