# V5.0.0

本版只支持 V4.14.1 的 LRX3 数据；V4.13 及更早版本的数据、备份、日志与数据包不再兼容。

## 主要变化

- 数据包升级为 V2，全部必填字段缺失时整包拒绝，不再按旧包语义保留本机设置。
- 移除 `periodLabels` 旧时段字段，时段只保留 `periods` 单一真源。
- 移除旧目录迁移、LRX2 解码、旧日志合并与旧固定名备份恢复入口。
- 表格导入缺少“日期”列时直接报错，不再按今天导入。
- 安装器不再包含旧版迁移工具或旧版残留清理逻辑。
- 版本升为 V5.0.0。

## 升级说明

从 V4.14.1 可直接覆盖安装。V4.13 及更早版本不支持升级到 V5；请留在 4.x，或在 4.x 中导出数据后重建。
