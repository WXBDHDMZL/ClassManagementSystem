## 本版目的

让程序可以直接从 GitHub 获取正式发布的安装包，不必手动寻找下载地址；同时在界面中提供公开源码地址。

## 调整内容

### 程序更新

- 「设置 → 系统与安全 → 日志与维护 → 程序更新」新增“检查更新”按钮，联网读取 GitHub 上最新正式版本。
- 有新版本时显示版本号、安装包大小与发布说明，确认后自动下载。
- 下载完成后优先按 GitHub 提供的 SHA-256 摘要校验；没有摘要时读取同目录的 `.sha256` 文件校验。校验不通过会删除文件并提示。
- 校验通过后交给现有安装流程：退出程序、静默安装、成功后重新打开。
- 仍保留“选择更新包”，可手动选择本地 `.exe` / `.msi` 安装包。
- 检查与下载只在用户主动点击时访问 `api.github.com`、`github.com`、`objects.githubusercontent.com` 等 GitHub 域名，使用 HTTPS，不发送班级数据。

### 源码入口

- 关于页的“源码获取”已填入公开仓库地址：https://github.com/WXBDHDMZL/ClassManagementSystem

## 兼容性说明

- 不改变主数据、加密、备份与日志文件格式；已有数据、备份、日志继续可用。
- 不改变现有记录、名单、统计、导出功能。
- 升级只替换程序文件，不删除「文档\班级管理系统」中的记录、名单、原因库、设置、日志或备份。
