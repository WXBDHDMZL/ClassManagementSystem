# 班级管理系统 V3.7.0 更新说明

- 发布日期：2026-11-01
- 类型：旧兼容层清理版
- 上一版：V3.6.0+141 ｜ 本版：V3.7.0+142

## 本版目的

V3.6.0 已完成旧数据迁移验收，当前正式数据已全部是新格式。本版按确认结果删除不再需要的旧格式兼容代码，并清理旧版本地文件，降低后续维护成本。

## 改动

### 删除旧格式读取

- 不再读取 LRX1 旧加密格式，只接受当前 LRX2；
- 数据目录固定为 `文档\班级管理系统\`；新目录没有数据、但文档根目录仍有旧主文件或旧备份时，首次启动只读复制到新目录，旧文件保留不删；两者都无法读取时暂停保存，避免生成空库；
- 不再接受旧版单轮 SHA-256、两段式 `p2:` 密码哈希；当前 `p2:100000` 格式不受影响；
- 不再读取旧明文操作日志、错误日志、插件状态、插件参数与密码锁定状态；
- 不再迁移 `%USERPROFILE%\Documents\班级管理系统_插件` 旧插件目录；
- 删除旧时段 key 别名、旧主题字符串、旧密码字段、旧考勤方向/跨零点一次性迁移逻辑；
- 删除通知在无 `AppNotificationScope` 时使用旧 Overlay 的回退；缺少作用域时明确报错，测试统一挂 Scope；
- 删除仅服务于旧迁移的测试用例，并补充旧布局升级、日志枚举、设置导入与通知作用域回归，测试基线由 755 调整为 738。

### 正式数据保持不变

本版没有改写正式数据，仍为：

- 记录数已脱敏；
- 学生数已脱敏；
- 日期数已脱敏；
- 0 条考勤；
- 备注中“收作业时”已清理为 0 条（此前单独完成）；
- 管理密码哈希为当前 `p2:100000` 格式。

### 旧本地文件清理

按用户确认，以下旧文件已删除：

- `文档\班级管理系统\备份\` 下 11 个旧 schema 自动备份；
- 根目录两份考勤清理前备份；
- 旧明文 `class_management_data.json`（19 条测试记录）；
- 开发数据 `class_management_data_dev.enc`、`.bak` 与 `班级管理系统_备份_DEV`；
- 旧插件目录 `<用户文档>\班级管理系统_插件`；
- 旧安装包 v3.1.3、v3.5.0、v3.6.0 与备注清理同步包、旧打包日志。

保留：当前主数据与 `.bak`、当前日志、当前插件、密码锁定状态、备注清理前的手动回滚点。
