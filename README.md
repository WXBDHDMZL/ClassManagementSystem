# 班级管理系统（Class Management System）

**V4.9.7** · 作者：WXBDHDMZL · © 2026 WXBDHDMZL · 许可证：AGPL-3.0-only

一款面向班主任的 Windows 桌面应用，用于快速记录学生的表扬与批评表现，按时间段归档、支持历史查询与 Excel 导出，帮助班级管理留痕、统计有据。

## 功能特性

- **快速记录**：点击学生卡片即可记录表扬/批评，按当前时刻自动预选时间段（就餐、早读、上课、午休、晚修等 9 个时段，同类的早中晚三餐与上午下午课程已合并），原因一键多选，可按手动顺序或使用频率排序，支持自定义原因与备注；新增、修改或删除成功后可在顶部提示右侧点「撤销」，2.5 秒内撤回最近一次记录变更（单条或批量）
- **学生快速搜索**：主页学生网格上方可按姓名实时筛选，输入即缩小名单；搜索时只显示学生卡片、不显示「批量」入口，清空搜索后恢复完整名单；可在「设置 → 日常使用 → 外观与窗口 → 主页学生搜索」关闭搜索框
- **批量记录**：学生网格第一位提供「批量」入口，可按所选时段的归属日一次写入多条记录（凌晨就寝归前一天），批量记录带「批量」标记、备注默认「批量」
- **天气**（默认关闭）：可在「外观与窗口」开启顶栏天气并选择地区，开启后每 15 分钟刷新；关闭时不发起天气请求
- **今日总览**：右侧面板实时展示当日全部记录，表扬/批评/批量/追加标签以语义色区分；跨天后自动切到新一天，不再显示前一日记录
- **统一通知**：所有操作成功/失败提示统一为窗口最上层的顶部长胶囊（位于设置页、对话框之上，普通提示不拦截鼠标，带「撤销」的提示可点击），最多同时显示 3 条、最新在最上，超出时优先淘汰最早的普通提示，相同提示去重；数据保存失败时改为顶部常驻红色胶囊，恢复后自动消失；身份未选择提示也走同一套通知，不再使用底部 SnackBar
- **历史管理**：多日期查询、跨日期"选中之间"补齐、事后追加记录（受记录密码策略控制）
> 说明：考勤相关功能在生产版本中处于关闭状态（代码保留能力与历史数据），以下考勤条目仅在启用后适用。

- **考勤登记**（可在设置中开关，默认关闭）：默认全员到齐，只登记请假、缺勤、迟到等异常；登记走"选学生（可多选）→ 选时间段（含全天）→ 选状态"，与记录的操作顺序一致；窗口显示"应到/实到/各状态人数"，异常记录按时间段分组、标注记录人、点 × 可撤销，可切换日期补录、清空全部时段与导出考勤表（只列异常名单，表尾汇总其余正常出勤 N 人；启用操作身份时含记录人列）；考勤保存登记时的时段显示名快照，之后时段改名/删除不影响历史考勤显示
- **考勤与批评双向同步**：登记迟到/早退/缺勤会自动生成对应批评记录（迟到/早退/旷课），反之在记录里选这些原因也会自动登记考勤；映射可在设置里逐项修改（留空即不同步，如请假）；撤销或删除任一侧都会同步；「批评」类型停用时不再新生成同步记录，已有记录仍随考勤更新或撤销
- **统计周期**：每周起始日可选周一/周日/周六，用于周统计与趋势聚合
- **Excel 导出**：导出今日记录、按日期导出/合并导出/分别导出，以及表扬/批评次数排名表（未开启考勤功能时，记录导出不附考勤异常名单）
- **深浅色主题**：浅色 / 深色 / 跟随系统三态切换，Material 3 配色，实时生效并持久化
- **本地加密存储**：所有数据仅保存在本机文档目录，采用「每文件随机盐 + HMAC-SHA256 流加密 + 完整性校验」加密落盘（可识别损坏/被改动的文件并走备份恢复），不收集、不上传班级数据
- **操作权限（班主任管理）**：普通模式可查看、统计和普通导出，并按操作身份权限新增记录、登记考勤、在本人窗口内改删自己创建的记录。班主任身份必须验证管理密码；认证期间拥有完整管理权限，可修改/删除任意记录、导入、修改名单/原因/时段、操作数据包与备份、恢复出厂、程序更新；退出、超时或重启后立即失去管理权限。管理密码只在本机加密保存；**查看记录、统计与普通导出不需要密码**。
- **忘记密码**：可在"设置 → 系统与安全 → 安全与密码"生成一次性恢复码（只显示一次、只存加盐哈希）；忘记管理密码时在密码框点"忘记密码"，输入恢复码即可重置管理密码，恢复码用后作废。恢复码不联网、不存明文。若连恢复码也未保存，可在程序完全退出后用仓库内 `tools/local_recovery` 离线工具重置（不进安装包、不随软件分发）
- **本地文件加密范围**：主数据与自动备份、运行日志、密码锁定状态，均使用与主数据相同的 LRX2 加密（每文件随机盐/随机数 + HMAC 完整性校验）；V3.7.0 起不再读取旧版明文日志/状态文件。用户主动导出的 Excel、数据包保持标准可读格式。该加密用于防误看/防损坏，密钥内置在程序中，不等同于口令加密
- **操作身份**（默认关闭）：选择本次操作使用的身份，并把身份快照写入记录人以留痕。班主任身份需要验证管理密码，认证后进入班主任管理并拥有完整管理权限；其他身份只拥有配置的普通权限（新增记录、考勤登记、本人窗口）。
- **统计看板**：按周/月/自选区间查看概览、排行榜、每日趋势与学生明细；趋势图按区间长度自动按天/周/月聚合；提供"对比与关注"——表扬批评比、与上一段等长区间的环比增减、需关注学生名单（默认周 3 次、月 8 次、学期 20 次，阈值可调）；可导出表扬/批评分类型汇总、明细、每日统计、对比与关注等统计报表与排名表
- **设置与数据管理**：设置采用左侧分类导航，按「日常使用（统计口径、外观与窗口）/ 记录与名单（记录设置、名单与原因库）/ 时间与考勤（时间段、考勤）/ 数据管理（导出与导入、备份与恢复）/ 系统与安全（操作身份、安全与密码、日志与维护）」分组，「关于」固定在底部；记录设置、日志与维护以及名单、时间段、考勤、导出导入、备份恢复需要管理密码，统计口径、外观与窗口、关于免密码；管理会话超时后，这些页面会锁定并隐藏内容，需重新验证；关闭管理密码、生成或关闭恢复码前也要再次输入当前密码；可自定义时段名称与时间范围、记录默认操作类型与自动预选、考勤开关与考勤状态项；「导出与导入」提供记录表格导入导出、学生名单导入与完整数据包（含原因库、时间段、考勤与考勤状态项），原因库、时间段、考勤等分类统一走数据包；**导入记录时可勾选“同时按当前考勤映射补登考勤”**（已有考勤不覆盖）；缺少日期列的旧表格必须确认后才按今天导入；数据包恢复时可一并对齐名单、原因库、时段与考勤状态项；备份与恢复独立成页（备份位置可单独设置、频率与保留份数可选、恢复时按列表选择；每次备份会同时生成同名 `.logs` 日志快照，恢复时可勾选“同时恢复日志”，只合并缺少的条目；列表也包含上一份自动备份 `.bak`）；整包还原、从备份恢复、恢复出厂前会先自动备份，失败则中止；成功提示只在落盘成功后显示
- **托盘后台常驻**：系统托盘图标常驻，关闭窗口可选"每次询问 / 直接退出 / 最小化到托盘 / 最小化到悬浮球"，可记住选择；单击托盘图标恢复窗口，托盘菜单可退出程序
- **桌面悬浮球**：可把主窗口收进一个 56×56 的置顶小圆球（独立原生窗口、半透明、可调透明度、不出现在任务栏），单击圆球立即恢复主窗口，按住可拖动且会记住位置；右键圆球可打开快捷菜单（快速记录、今日概览、不透明度、锁定位置、收起到托盘、设置/退出），右键“快速记录”可多选学生批量表扬或批量批评，今日概览会显示当天表扬/批评数量；主窗口最小化时也会进入悬浮球模式；托盘菜单也可随时切换
- **单实例保护**：重复启动不会开出第二个程序，只会唤起已在运行的窗口，避免两份进程同时写数据
- **可自定义项**：界面字号（小/标准/大/特大）、表扬/批评可分别启用、原因按手动或使用频率排序、导出文件名前缀与记录列勾选、统计区间（本周/本月/近 7 天/近 30 天/本学期/全部记录/自定义）可记忆、顶栏天气开关、开机自动启动（托盘 / 悬浮球）
- **运行日志**：增删改记录、考勤登记与撤销、名单与原因改动、导入导出、备份恢复等关键操作与界面异常统一写入 `文档\班级管理系统\日志\班级管理系统_日志.txt`（单一文件、逐条加密落盘；日志文件与日志目录带“拒绝删除”权限，资源管理器删除会被系统拒绝，程序运行期间还会保持文件句柄作为第二层保护，避免误删；查看与导出入口：设置 → 系统与安全 → 日志与维护）
- **删除无需二次确认**：删除记录时直接按密码/身份策略校验后执行，成功提示右侧提供「撤销」，误删可在 2.5 秒内恢复
- **更新与恢复出厂**：设置 → 系统与安全 → 日志与维护 → 程序更新 可选择安装包完成覆盖升级（自动安装并在成功后重新打开；失败或取消班主任管理授权时会重新打开并提示）；恢复出厂设置位于「备份与恢复 → 危险操作」，一键清空数据（两次确认；需要进入班主任管理；执行前自动备份当前数据，备份失败则中止；可在第二次确认时勾选“同时清除全部备份与日志”）

## 构建与打包

开发环境：Flutter 3.44（stable）、Visual Studio 2026（含 C++ 桌面工作负载）、Inno Setup 6/7（制作安装包）。

```bat
:: 1. 构建 Release 版（Dart 代码混淆，符号表输出至 debug_info\，勿随包分发）
build.bat

:: 2. 测试 build\windows\x64\runner\班级管理系统.exe，确认无误后再打安装包
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\installer.iss
::    也可双击 installer\build_installer.bat（会自动查找 Inno Setup 6/7）
```

产物：

- 测试运行：`build\windows\x64\runner\班级管理系统.exe`（可直接运行，需与同目录 data、dll 一起）
- 安装包（按需打包，用户要求时生成）：`installer\output\班级管理系统_安装包_v<版本>.exe`（含 exe、flutter_windows.dll 与 data 全部资源，勿只分发 exe）

注意：`build.bat` 会先跑版本号与规则门禁（`tools/check_version.py`、`tools/check_rules.py`），再调用 vcvars 初始化 Visual Studio 编译环境，前提是本机 VS 安装路径与脚本内一致；**项目文件夹路径必须为纯英文/ASCII**（Flutter 的 AOT 混淆工具链不支持中文路径，会编译失败），产物 exe 文件名为中文不受影响。

## 数据存储

所有程序内部文件都集中在文档目录下的 **`班级管理系统`** 文件夹：

```
文档\班级管理系统\
  class_management_data.enc        主数据（LRX2 加密）
  class_management_data.enc.bak    上一份自动备份
  class_management_auth_guard.json 密码锁定状态（内容加密）
  备份\                             自动备份（同名 .logs 为日志快照）
  日志\                             运行日志（单一文件，内容加密）
```

主数据格式：`LRX2` 魔数 + 随机盐 + HMAC-SHA256 流加密 + 完整性标签；保存采用原子写（先写临时文件再替换），每次保存前自动保留 `.bak`，主文件损坏时用备份恢复。V3.7.0 起数据目录固定为上述位置；升级时若新目录没有数据、但文档根目录仍有旧主文件或旧备份，会一次性只读复制到新目录（旧文件保留不删）。应用不会上传班级记录、考勤与名单；天气查询仅发送所选地区名称或坐标。

## 隐私与数据安全

- **数据只存本机**：记录、考勤与名单全部保存在本机 `文档\班级管理系统\` 里的 `.enc` 文件，
  不会上传；天气功能会向 Open-Meteo/Photon 发送所选地区名称或坐标以获取天气，
  不包含学生姓名、记录或名单。
- **程序不内置真实学生名单**：首次启动与恢复出厂都是空名单，名单由用户在本机导入或手动添加。
  仍请勿公开分发数据文件、日志或含真实姓名的旧安装包（包括公开的代码托管平台）。
- 数据文件是"混淆加密"（密钥内置于程序），能防误读、防误改，**但不防刻意逆向**；
